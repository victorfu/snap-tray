錄影支援 macOS、Windows 與啟用錄影功能的 Linux X11 版本。Linux 使用系統 FFmpeg 函式庫與 PulseAudio（或 PipeWire 的 PulseAudio 相容服務）。

## 錄影入口

- 托盤選單：Record Screen
- 錄影快捷鍵：至 Settings > Hotkeys 設定 Record Screen

## 錄影生命週期

1. 多螢幕環境下，依提示選擇要錄製的螢幕。
2. 錄影會在選定螢幕上直接開始。
3. 透過浮動控制列查看時間、暫停或繼續，以及停止錄影。暫停時控制列會顯示「已暫停」，時間也會停止。Linux 錄影時會隱藏浮動控制列，請使用托盤選單暫停、繼續或停止。
4. 編輯模式下按 Stop 會開啟預覽；快速模式下則立即儲存檔案。

## 錄影前選擇範圍

在「設定 > 錄影」開啟 **錄影前選擇範圍**（或在錄影前設定中開啟 **先選擇範圍**），即可在開始前先選好要錄的範圍。預設關閉：和以前一樣直接錄製整個螢幕。

選好螢幕後畫面會變暗：拖曳畫出範圍、在範圍內拖曳可移動，需要時可選擇比例（自由、16:9、4:3、1:1、9:16）。標籤顯示以影片像素計的大小；範圍每邊至少 64 像素，且只能在同一個螢幕上。按 **錄影**（或 **Enter**、雙擊）開始，**全螢幕** 錄製整個螢幕，**取消**（或 **Esc**）則不錄影。

- **編輯模式** 仍會錄製整個螢幕。預覽會以裁切至該範圍的狀態開啟，你可以移動或調整裁切、復原回此範圍，或重設以看到全部畫面。當機後復原的錄影也會以同樣的裁切開啟，復原清單會註明檔案內含整個螢幕。
- **快速模式** 只錄製該範圍，因為之後沒有預覽可以裁切。

錄影時，範圍外會顯示一個框標示錄影範圍，暫停時變為琥珀色。在 macOS 與 Windows 上這個框不會被錄進影片。Linux X11 的擷取無法排除它，因此只在快速模式顯示，畫在錄製範圍外側；編輯模式會錄製整個螢幕，因此不顯示框，之後調整裁切也不會露出框。選擇範圍期間，截圖、螢幕畫布與釘選會等到完成或取消後才能使用。

編輯模式的暫存錄影，以及等待復原的錄影，在儲存或捨棄前都包含整個螢幕，也包括範圍以外的內容。

## 快速模式與編輯模式

錄影前設定與「設定 > 錄影」中的 **錄影後** 決定按下 Stop 之後的行為，兩處調整的是同一個設定。

| | 編輯模式（**在預覽中編輯**） | 快速模式（**立即儲存**） |
| --- | --- | --- |
| 按 Stop 後 | 開啟預覽：修剪、裁切、剪掉片段、縮放、遮罩、加入效果後再儲存 | 開啟儲存對話框；開啟自動儲存時直接存檔 |
| 錄製方式 | 先以高品質 MP4 錄製，儲存時再轉成你選的格式與品質 | 直接以輸出格式與品質錄製 |
| 音訊 | 會錄製（GIF 與 WebP 匯出仍無聲） | 只有 MP4 有聲音；GIF 與 WebP 沒有 |
| 游標、視窗與按鍵軌道 | 隨暫存錄影保留，供編輯使用 | 不錄製 |
| 儲存之後 | 預覽關閉（若開啟可編輯專案則保留專案） | 可選擇 **複製檔案**，方便貼到聊天或資料夾，或 **在資料夾中顯示** |

快速模式與過去關閉「顯示預覽」的行為完全相同。托盤提示會標示目前錄影使用的模式。磁碟空間監測、磁碟快滿時安全停止，以及當機後復原錄影，在兩種模式下都一樣運作。在只能直接錄製 MP4、沒有預覽的系統上，一律使用快速模式。

錄影時，托盤選單也提供「暫停錄製／繼續錄製」，macOS 與 Windows 另有「顯示錄影控制列」，兩者都可在「設定 > 快捷鍵」指定快捷鍵。

在預覽視窗中，垃圾桶按鈕、**Esc** 與視窗的關閉按鈕都會先詢問才刪除錄影。在詢問畫面按 **Esc** 或 **Enter** 會保留錄影；按 **Tab** 可移到「捨棄」。正在框選裁切範圍時，**Esc** 只會取消裁切。

錄影期間，托盤或選單列圖示的角落會顯示狀態標記：準備或倒數時為圓環、錄影中為紅點、暫停時為暫停符號、影片收尾時為三個點。將游標移到圖示上，可查看目前狀態、已錄製時間（不含暫停）及正在錄製的螢幕。若托盤位於被錄製的螢幕上，圖示可能會出現在影片中。

## 裁切錄影

錄影一律擷取整個螢幕。若只想保留其中一部分，請在停止錄影後於預覽視窗中裁切：

1. 在預覽工具列中按一下 **裁切**。
2. 在影片上拖曳以畫出裁切範圍，再於範圍內拖曳可移動，或拖曳控點調整大小。邊緣會吸附到影片邊緣與中心線。將游標移到視窗上會亮起，點一下即可裁切成該視窗在影片目前時間點的範圍。
3. 按 **Enter** 套用，或按 **Esc** 取消。套用後的尺寸會顯示在影片左上角，按 ✕ 即可清除。
4. 另存為 MP4、GIF 或 WebP。匯出的 MP4 會保留音訊。

裁切時，時間軸下方那一列提供：

- **比例預設**：自由、原始、16:9、4:3、1:1、9:16。拖曳畫框、調整大小與點選視窗都會維持所選比例。
- **X、Y、W、H**：以影片像素表示的裁切範圍。輸入的數值會依編碼器需求調整為偶數並符合最小尺寸，畫框旁的尺寸標籤一律顯示實際會輸出的大小。
- **方向鍵** 每次移動 2 像素（按住 Shift 為 10 像素）。在欄位中輸入的按鍵只作用於該欄位；在欄位中按 **Esc** 只會還原欄位內容。

有修剪範圍時，可在時間軸下方以 `m:ss.mmm`（例如 `0:07.250`）輸入開始與結束時間。

每次套用的裁切與修剪都能復原（**Ctrl+Z**）與重做（**Ctrl+Shift+Z** 或 **Ctrl+Y**）。按 ⟲ 可回到未編輯的錄影（同樣可復原），按 ◧ 或 **\\** 可與原始畫面比較。時間軸下方會顯示原始與輸出的像素尺寸、保留的時長，以及所選格式是否有音訊。

## 剪掉片段與變速

時間軸不只能修剪頭尾。在預覽中：

1. 移動播放位置後按 **分割**（或按 **S**）在該處切開錄影。分割點會以小直條顯示在時間軸上；拖曳可移動，雙擊可把兩段合回去。
2. 播放位置在某個片段中時，**剪掉片段**（或按 **Delete**）會把它排除在匯出之外，時間軸上會以陰影表示；**保留片段** 可放回來。
3. **片段速度** 設定該片段在匯出中的播放速度：0.5×、1×、1.5×、2× 或 4×，速度會顯示在片段上方。

預覽會照編輯結果播放：跳過剪掉的片段，各片段以自己的速度播放；影片下方的時間會顯示匯出長度。剪輯與變速可以像其他編輯一樣復原，**重設裁切與修剪** 會移除它們。

匯出時會依序接起保留的片段。游標平滑、動態模糊與點擊圓環都不會跨越剪接點，所以被剪掉片段中的點擊不會出現。正常速度的片段保留聲音，每個接縫都維持音畫同步；**這一版變速片段沒有聲音**。只剪掉第一段或最後一段時等同修剪。在 macOS 與 Windows 上，GIF 與 WebP 可使用剪輯與變速；這些平台的 MP4 會拒絕匯出並說明原因。

## 磁碟空間

SnapTray 會在開始前與錄影期間每隔幾秒檢查錄影檔所在位置的可用空間。門檻依錄影而定：保留完成檔案所需的空間、數秒的錄影量，以及開啟預覽時匯出副本所需的空間。

- **開始前**：空間幾乎用盡時不會開始錄影，並顯示剩餘空間。
- **空間不足**：只提示一次，並附上估計可錄的分鐘數（尚無估計時改顯示剩餘空間）；托盤提示會顯示「磁碟空間不足」，釋出空間後即解除。
- **即將用盡**：會自動停止錄影並正常完成檔案，目前錄到的內容都會保留，不會被捨棄。
- **無法得知**：若讀不到剩餘空間，SnapTray 會提示一次並繼續錄影，不會當成空間無限。

從預覽匯出前會先確認有足夠空間放新檔案，存到其他磁碟時也會檢查目的地。空間不足時不會刪除任何東西：釋出空間或選擇其他位置後再儲存即可。即使剩餘空間看起來足夠，寫入錯誤（例如外接磁碟被拔除）仍會照常回報。

## 錄影被中斷時

如果錄影被 SnapTray 以外的原因結束，處理方式和按下「停止」相同：檔案會正常完成、開啟預覽（或儲存對話框），目前為止錄到的內容全部保留。通知會說明停止的原因：

- 正在錄製的螢幕已中斷連線；
- 該螢幕的解析度、縮放或方向改變了（輸出尺寸是固定的，所以 SnapTray 會停止錄影，而不是讓畫面變形）；
- 從系統本身的控制項停止了螢幕錄影、權限被撤銷，或擷取停止運作；
- 磁碟空間即將用盡（見上方）。

即使同時發生多個原因，錄影也只會結束一次，並回報最先發生的原因。錄影中拔掉麥克風時，錄影會繼續（不含麥克風聲音），SnapTray 會提示；它不會自行切換到其他麥克風。如果檔案本身無法完成，SnapTray 會說明是否保留了可播放的部分（在 Linux 上可從托盤選單復原，見下方）。只有在你選擇「捨棄」時，錄影才會被刪除。

## 錄影中的滑鼠游標

錄出的影片本身不含滑鼠游標。錄製會開啟預覽的錄影時，SnapTray 會在錄影旁另外記錄游標：位置、外觀，以及按鍵按下的時間。不會記錄任何鍵盤輸入。這份記錄跟著暫存錄影，在你儲存或捨棄時一併刪除；儲存的影片與匯出檔都不會包含它。之後的編輯功能會用它來顯示、放大或標示游標。

在 Linux（X11）上會包含游標外觀與點擊；macOS 與 Windows 目前只保留位置，游標會以一般箭頭繪製。如果這份記錄無法寫入，錄影本身不受影響。

### 預覽中的游標效果

錄影有這份記錄時，預覽會在格式按鈕旁顯示游標控制項。預覽中看到的效果就是匯出時繪製的效果，並套用相同的裁切與修剪：

- **指標**：在匯出的影片中顯示或隱藏滑鼠游標。
- **大小**（1×、1.5×、2×、3×）：把游標畫得更大。
- **平滑**（關、低、中、高）：讓抖動的移動路徑更平順。點擊永遠保留在實際發生的位置與時間。預設為關。
- **點擊**：在每次點擊的位置短暫顯示圓環。需要有錄到點擊（Linux）。
- **指標選項** 提供更多效果，預設皆為關閉：
  - **閒置時隱藏**（1 秒、2 秒、5 秒）：游標靜止超過設定時間後淡出；在移動或點擊前會先淡入，所以點擊當下一定看得到游標，點擊圓環也不會被隱藏。
  - **動態模糊**（低、中、高）：快速移動的游標後方留下短暫拖影；靜止的游標維持清晰。
  - **結尾停止移動**（0.5 秒、1 秒、2 秒）：輸出片段的最後幾秒游標保持不動，不會拍到移去按停止的動作。以修剪後的結尾為準。
  - **在此隱藏指標**：從播放位置起隱藏游標（含點擊圓環）兩秒。隱藏區段會以灰色細條顯示在時間軸下方；點選後可輸入開始與結束時間，或刪除。

上次的選擇會被記住（隱藏區段只屬於該次錄影，不會保留），也可以像裁切與修剪一樣復原（**重設裁切與修剪** 會保留它們）。繪製游標代表儲存時需要重新編碼；隱藏游標且沒有其他編輯時，未編輯的錄影仍會直接儲存而不重新編碼。在 macOS 與 Windows 上，GIF 與 WebP 匯出可使用游標效果；這些平台的 MP4 匯出目前還不會繪製，預覽中會加以說明。

### 快捷鍵提示

SnapTray 可以把錄影時按下的快捷鍵顯示在影片中，方便製作教學影片（例如「Ctrl + C」、「Ctrl + Shift + T」）。**除非在錄影前開啟，否則絕不記錄按鍵**：在錄影前的設定畫面（**記錄快捷鍵**）或「設定 > 錄影」（**記錄按鍵**）開啟。記錄按鍵期間，系統匣狀態會顯示。

- **僅快捷鍵**（開啟後的預設）只保留與 Ctrl、Alt 或 Super 一起按下的鍵，以及 Enter、Esc、Tab、方向鍵、F 鍵等按鍵；一般打字（包括 Shift+字母）不會保留。
- **所有按鍵（包括輸入的文字）** 是另外的選項。輸入密碼時請勿使用。

按鍵只與暫存錄影一起保存，不含視窗標題或應用程式名稱，並隨暫存錄影一起刪除：絕不會出現在儲存的檔案或歷史紀錄中。暫停錄影時按下的鍵不會保留。在 Linux（X11）上以被動方式讀取按鍵，不會攔截鍵盤；macOS 與 Windows 目前還不會記錄按鍵，選項中會加以說明。

錄影有按鍵資料時，預覽中的 **按鍵** 可以把它們畫進匯出檔：**按鍵：開／關**、**位置**（下方、左下、右下、上方）、**大小**、**深色／淺色**，以及提示顯示多久（1、1.5 或 2.5 秒）。連續按下的鍵會一起顯示，重複的快捷鍵只顯示一次並加上次數（例如「Ctrl + Z ×3」）。提示會跟著剪輯（#185）：被剪掉片段中的按鍵不會出現。和其他效果一樣，Linux 的 MP4 以及所有平台的 GIF 與 WebP 都能繪製提示。

### 縮放與平移

全螢幕錄影分享後，按鈕與文字常常顯得很小。預覽可以放大錄影的局部：

- **自動縮放** 會放大你點擊或拖曳的位置：相近的點擊共用一段穩定的縮放，距離較遠的操作會平移過去，沒有操作時回到完整畫面。需要有錄到點擊（Linux）；分散在大半個螢幕的操作會維持完整畫面。再次執行會取代自動產生的縮放，但保留你新增或修改過的縮放。
- **新增縮放** 會在播放位置加入兩秒、2× 的縮放，若知道游標位置則以游標為中心。
- 縮放會以時間軸上方的色條顯示。點一下即可編輯：選擇 1.5×、2×、2.5× 或 3×、輸入起訖時間，或點擊影片移動中心。**減少動態** 讓所有縮放更小、更慢且不直接平移，**縮放：開／關** 可暫時關閉全部縮放而不刪除，**刪除** 移除一段縮放。

預覽顯示的就是匯出時繪製的結果，縮放也能和其他編輯一樣復原。縮放不會顯示錄影或裁切範圍以外的內容。打字與捲動不會被記錄，因此不會觸發自動縮放。和游標效果相同，Linux 的 MP4 以及所有平台的 GIF 與 WebP 都可使用縮放。

### 遮蔽敏感區域

分享前，可以用 **新增遮罩** 遮住帳號名稱、聊天內容、通知或其他私密內容。遮罩一開始位於畫面中央、套用整段錄影；拖曳可移動，拖曳角落可調整大小。選取遮罩時可以選擇：

- **實心**：以黑色覆蓋該區域。這是預設值，也是唯一會真正移除內容的樣式。
- **像素化** 或 **模糊**：只會弱化細節，無法保證文字或臉孔不能被辨認或還原；不能被看見的內容請使用實心。
- **整段錄影**，或指定遮罩的起訖時間。

遮罩會燒錄進匯出的 MP4、GIF 或 WebP，預覽也會直接在實際畫面上顯示，並在任何裁切或縮放之前套用，因此縮放不會露出被遮住的內容。每個遮罩都會提早一點點開始，確保不會有任何一格在開始時露出內容。遮罩可以和其他編輯一樣復原；**重設裁切與修剪** 會保留遮罩。

**遮罩只存在於匯出的檔案中。** 未遮蔽的錄影是暫存檔：在你儲存之前（包括取消或儲存失敗後）都還能在預覽中使用；遮蔽後的檔案一旦儲存完成，SnapTray 就會刪除它。如果你也需要未遮蔽的版本，請先在沒有遮罩的情況下儲存一次。SnapTray 不會上傳任何錄影。如果所選格式在你的系統上無法繪製遮罩（目前為 macOS 與 Windows 上的 MP4），SnapTray 會拒絕匯出並說明原因，而不會存出沒有遮罩的檔案。遮罩不會自動追蹤：內容若有移動，請為各個時間範圍分別加入遮罩。

### 文字與圖片

**加入文字** 會從播放位置起在影片上加入三秒的標題或說明；**加入圖片** 可加入圖片檔（PNG、SVG、JPEG、WebP），例如標誌，預設顯示整段錄影。疊加會以細條顯示在時間軸下方，點選即可編輯：

- 文字：在輸入框中輸入（可多行）、放大或縮小、選擇顏色、深色或淺色底框，以及對齊方式。
- 圖片：放大或縮小，以及不透明度。
- 兩者：在影片上拖曳可移動、拖曳角落可調整大小、選擇整段錄影或輸入開始與結束時間，或刪除。疊加會淡入淡出。

疊加位於匯出的畫面上：裁切後位置不變、不會跟著縮放放大，遮蔽也不會蓋住它們。圖片在加入時就會讀進來，之後刪除或移動原始檔不影響匯出。疊加可以像其他編輯一樣復原，**重設裁切與修剪** 會保留它們。和遮蔽一樣，Linux 的 MP4 與所有平台的 GIF、WebP 都能繪製；其他情況 SnapTray 會拒絕匯出 MP4 並說明。「設定」中的浮水印仍和以前一樣在錄影時加上，疊加不會取代它。

### 影片外框

預覽中的 **外框** 會把匯出的影片放在背景上，就像截圖的美化功能。第一次會以截圖美化的外觀為起點（預設關閉）；之後會記住你上次替錄影設定的外框。可以像其他編輯一樣復原，**重設裁切與修剪** 會保留它。

- **背景**：漸層預設、白色、黑色、**模糊影片**（以模糊後的影片本身當背景），或 **圖片…**（選擇圖片檔）。
- **內距**、**圓角**（無、小、中、大）、**陰影** 與 **邊框**。大小會依影片比例調整，小影片和 4K 錄影看起來一樣。
- **比例**：自動，或 1:1、16:9、4:3、9:16、2:1，多出的空間由背景填滿。

外框會讓匯出檔比裁切後的畫面大出內距（與比例）的部分；MP4 匯出選項再縮放加上外框後的影片。外框最後才繪製，包住已套用遮蔽、縮放與游標的畫面；模糊背景取自已遮蔽的畫面，所以遮蔽蓋住的內容不會從周圍透出。除了編輯裁切或比較原始畫面時，預覽都會顯示外框。和遮蔽一樣，外框可用於 Linux 的 MP4，以及所有平台的 GIF 與 WebP。

## 復原未儲存的錄影

在錄影被儲存或捨棄之前，SnapTray 會在錄影檔旁保留一份小紀錄。若 SnapTray 在那之前停止（當機、斷電，或在預覽尚未儲存時結束程式），下次啟動會顯示提示，並可從托盤選單的 **復原錄製** 查看留下的錄影。每一筆都會顯示錄製時間、可播放的長度，以及原本應有的音訊是否遺失。按 **復原** 會在預覽中開啟以便儲存；按 **捨棄** 會刪除；按 **稍後** 則保留到下次。這些等待復原的檔案不會被 SnapTray 例行的暫存檔清理刪除。

在 Linux 上，錄影會分段寫入，因此中斷的錄影通常可以復原到最後一個片段（約每兩秒一段影片）。實際結果取決於磁碟與系統最後一次寫入的時間，並非保證。在 macOS 與 Windows 上，中斷的錄影目前還無法播放，只會列出以便捨棄；但正常結束卻尚未儲存的錄影在所有平台都能復原。

## 可編輯專案

一般情況下，檔案儲存後錄影就會刪除。在「設定 > 錄影」開啟 **保留可編輯專案**（預設關閉），就會改為連同你的編輯一起保留：裁切、修剪、剪掉的片段與速度、游標、縮放、遮罩、外框、快捷鍵提示、文字與圖片、音訊混音，以及匯出格式與 MP4 選項。系統匣選單的 **錄影庫** 會列出保留的專案，附縮圖、長度、大小與日期。**開啟** 會把專案帶回預覽，所有編輯都和你離開時一樣；再次儲存會匯出新檔案並更新專案。不儲存就關閉專案時，專案會維持上次儲存的狀態。專案是在從預覽儲存時保留的，因此此設定需要開啟 **顯示預覽**。外框使用的背景圖片會複製到專案中。若無法保留或更新專案（例如磁碟已滿），已儲存的檔案會保留，錄影也會留在預覽中，不會遺失；再次儲存即可重試。無法將檔案儲存到錄影庫本身的資料夾。

專案保存的是 **完整的螢幕錄影**，包括你模糊、遮蔽或裁掉的內容，以及游標、按鍵與分離的音軌，因此會佔用磁碟空間，也含有儲存的檔案裡沒有的內容。專案只留在這台電腦上 SnapTray 的應用程式資料資料夾，不會上傳。在錄影庫按 **刪除...** 可刪除專案（從專案儲存的檔案會保留），**刪除未變更超過以下時間的專案** 可在 7、30 或 90 天後自動刪除舊專案。專案與等待復原的錄影彼此分開，兩者都不會刪除對方的檔案。

## 錄影跟不上時

若電腦連續數秒來不及編碼擷取到的畫面，SnapTray 只會提示一次，托盤提示也會顯示「正在掉格」直到恢復。短暫延遲或畫面沒有變化不會被算進去。調低「設定 > 錄影」中的畫面更新率通常會有幫助。

錄影結束後，可在托盤選單按 **複製錄製診斷資訊**，複製一段簡短的文字摘要（擷取、編碼與掉格的數量和原因，以及佇列與編碼時間）。摘要不含影像、音訊、視窗標題或檔名，也不會傳送到任何地方。

## 儲存與取消

匯出 MP4、GIF 或 WebP 時，預覽視窗會顯示目前階段：轉換中（含百分比）、寫入檔案或儲存中。按 **取消** 可在任一階段於影格之間停止。錄影內容以及裁切、修剪設定都會保留，可調整設定或改選格式後再次儲存。

只有在檔案成功儲存後才會移除錄影。若在儲存對話框按取消，或檔案無法儲存，預覽視窗會維持原狀，可按 **重試** 或 **儲存** 再試一次。匯出期間關閉預覽視窗時，會先詢問要繼續匯出還是取消。

## 輸出格式

| 格式 | 適用情境 |
|---|---|
| MP4 (H.264) | 長時教學、產品 Demo |
| GIF | 短循環示意 |
| WebP | 輕量動態片段 |

### MP4 匯出選項

選擇 MP4 時，預覽中的 **MP4 選項** 可以設定匯出檔案，並在選項旁顯示輸出尺寸、影格率與預估檔案大小：

- **尺寸**：原始、1080p、720p 或自訂寬度。保持長寬比，且不會放大到超過錄影（或裁切後）的尺寸。
- **影格率**：原始、60、30 或 15 fps，不會高於錄影本身的影格率。
- **品質**：預設（使用「設定 > 錄影」中的品質）、低、中、高。
- **編碼格式**：H.264 到處都能播放；HEVC 在相同品質下檔案更小，但部分較舊的播放器無法開啟。只有系統能編碼 HEVC 時才可選擇。

預估值是目標位元率乘以匯出長度，實際檔案通常略小一些。上次的選擇會被記住。對這段錄影沒有影響的選擇（例如 720p 錄影選 1080p）不會讓未編輯的錄影失去快速路徑，仍會直接儲存而不重新編碼。游標效果、縮放與遮蔽會先畫在完整尺寸的畫面上再縮小，所以縮小後位置不變。目前在 macOS 與 Windows 上只有「品質」會生效；尺寸、影格率與 HEVC 會顯示但無法使用。

## 音訊選項

目前僅 MP4 錄影會在平台與音源支援時提供音訊：

- 麥克風
- 系統音訊
- 混合錄音

GIF 與 WebP 輸出不包含音訊。

### 錄影後調整麥克風與系統聲音

會開啟預覽的錄影若同時錄了麥克風與系統聲音，SnapTray 會在暫存錄影旁另外保留兩者各自的音軌，與影片使用相同的時間軸。影片本身仍是一般的混音，除非你調整，否則不會有任何改變。

在預覽中，**音訊**（MP4）可分別設定匯出時的：

- **麥克風** 與 **系統聲音** 音量（−12、−6、0、+6 dB），以及各自的 **靜音**。
- **降噪** 會降低麥克風在說話間隙的嘶聲、嗡嗡聲與環境噪音（高通濾波與柔和的噪音閘），幾乎不耗處理器。

調整時預覽會立即播放新的混音。全部維持 0 dB 且未靜音時，錄影會照原樣儲存；改變混音則會重新編碼聲音，並與影片保持同步，包含剪輯與變速（變速片段維持無聲）。兩條音軌會隨暫存錄影一起刪除，當機復原時也會和復原的錄影一起保留。只錄一種音源或在此之前錄的影片只有混音，不會出現音訊按鈕。目前只有 Linux 會錄製分開的音軌；macOS 與 Windows 的錄影仍只有混音。

### 錄影前檢查音訊

在「設定 > 錄影」開啟「錄製前顯示設定」後，每次錄影前都會出現簡短的設定畫面；有多個螢幕時，選擇螢幕的畫面也會一併顯示。畫面上可確認螢幕、麥克風與輸入裝置、系統音訊，以及輸出格式、預覽與倒數的摘要。變更會被儲存，之後的快速錄影會沿用。

按「測試麥克風」可查看即時輸入音量。只有在測試期間才會開啟麥克風；停止測試、開始錄影或取消時就會釋放，也不會播放聲音。無聲只會讓音量條保持空白，不會阻止錄影。

若已儲存的麥克風被拔除，清單會標示「未連接」，錄影時會改用預設麥克風並提示。

### 錄影中的音訊狀態

錄影期間，托盤或選單列的提示會分別列出麥克風與系統音訊的狀態：正在錄製、正在啟動、關閉、權限遭拒、找不到裝置、無法使用，或 GIF/WebP 不支援。若錄影中途降級（例如只剩系統音訊），通知消失後提示仍會持續顯示。

## 品質調校

在 Settings > Recording 可調整 FPS、畫質、倒數計時與預覽行為。

畫質滑桿決定的是儲存後影片的畫質。開啟預覽時,錄影本身會以高畫質擷取,讓裁剪與修剪不會損失細節;儲存時再轉成所選畫質,若檔案本來就夠小則直接保留原檔。若暫存錄影所在的磁碟剩餘空間不足約十分鐘的高畫質錄影,SnapTray 會改以所選畫質錄製並顯示警告。關閉預覽時,錄影會直接以所選畫質寫入。
