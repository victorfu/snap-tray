## 設定ページ

ページは作業ごとにまとめられています。各ページの冒頭には、タイトルとそのページで扱う内容を説明する一文があります。アップデートと情報は区切り線の下にあります。

録画と文字認識は macOS と Windows でのみ利用できます。Linux beta では
これらの機能が含まれていないため、両ページは非表示になっています。

### 一般

ログイン時に起動、表示言語、アプリテーマ、CLI のインストール/アンインストール。

macOS では、このページに画面収録とアクセシビリティの許可状態が表示され、ワンクリックでシステム設定を開けます。

### キャプチャ

- **キャプチャ後**：`全画面キャプチャ後の動作`（クリップボードにコピー、ファイルに保存、エディターを開く）。
- **範囲選択**：カーソル補助表示（拡大鏡）とショートカットのヒント。
- **自動ぼかし**：自動ぼかしで顔やテキストを隠すときのぼかしの種類と強度。

### ピンウィンドウ

デフォルトの不透明度、**ホバー時にコントロールを表示**、不透明度とズームを 1 回操作したときの変化量。

### 録画

フレームレート、デフォルト出力フォーマット、プレビュー優先エクスポート動作、音声ソース/デバイス、カウントダウン。

### 保存

- スクリーンショットと録画のフォルダー、およびファイル名フォーマットのテンプレート。
- 自動保存と「最後に使用したフォルダーを記憶」：有効にすると、Region、Pin、Beautify、ライブラリの「名前を付けて保存」ダイアログは、最後に手動で画像を正常に保存したフォルダーから開きます。自動保存では引き続き「スクリーンショット」フォルダーが使用されます。
- **ウォーターマーク**：透かし画像、スクリーンショット/録画への適用有無、不透明度、スケール、マージン、位置（プレビュー付き）。
- **ライブラリ**：ライブラリに保持するスクリーンショットの数。超えると古いものからライブラリから削除されます。保存済みのファイルはそのまま残ります。

### 文字認識

OCR の言語順序と認識後の動作。

### ホットキー

機能カテゴリ別の集中管理ホットキーエディター。ショートカットは個別にリセットでき、**すべてのデフォルトを復元** ですべて元に戻せます。

### アップデート

現在のバージョン、自動確認間隔、最終確認状態、手動で今すぐ確認。

### 情報

アプリ名、バージョン、著作権、作者、ウェブサイトリンク。

## 設定の検索とリセット

- サイドバー上部の **設定を検索**（`Ctrl+F`、macOS では `Cmd+F`）では、設定名、セクション名（例：「ウォーターマーク」）、ページ名で設定を探せるほか、アクション名でホットキーも探せます。`Up`/`Down` と `Enter` で結果を開くと、SnapTray はそのページに切り替え、該当する設定までスクロールして一時的に強調表示します。`Esc` で検索をクリアします。
- 設定は変更するとすぐに保存されます。設定がデフォルトと異なる場合、名前の左に **リセット** ボタンが表示され、その設定だけを元に戻せます。ホットキーには従来どおり **リセット** と **すべてのデフォルトを復元** があります。言語、テーマ、ログイン時に起動、入力デバイス、透かし画像、OCR 言語など、システムやユーザー自身の選択によって決まる設定にはリセットボタンはありません。

## 推奨ベースラインプロファイル

- macOS/Windows では標準チュートリアル用に 30 FPS MP4
- スクリーンショット用（利用可能な場合は録画用）の専用フォルダー
- 毎日の自動アップデート確認を有効化
