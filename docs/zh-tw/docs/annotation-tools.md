## 工具分類

### 繪圖

- Pencil
- Marker
- Arrow（直線與折線模式）
- Shape（矩形／橢圓）

### 說明標記

- Text
- Step Badge
- Emoji Sticker

### 隱私與修正

- Mosaic
- Eraser

## 鉛筆與螢光筆直線

使用 Pencil 或 Marker 時，先按住 `Shift`，再按住滑鼠左鍵拖曳，即可從起點到游標畫出任意角度的直線。直線沿用工具原本的樣式，包含螢光筆的透明效果；每筆直線可單獨 Undo／Redo。

起筆時的 Shift 狀態會決定整筆模式，拖曳途中按下或放開 Shift 不會切換。起筆時未按 Shift，則維持自由手繪。區域截圖、釘選視窗與螢幕畫布的操作相同。

## 建議編修流程

1. 先完成主體標線。
2. 統一顏色與線寬。
3. 補上文字與步驟編號。
4. 對敏感區域套用馬賽克。
5. 透過 Undo/Redo 微調後輸出。

## 使用建議

- 關鍵訊息維持單一強調色。
- Marker 適合高亮，不適合大量文字。
- 操作教學建議優先使用步驟標記。

## 匯出動作

- `Enter` 釘選
- `Ctrl/Cmd + C` 複製
- `Ctrl/Cmd + S` 儲存
