## 설정 페이지

페이지는 작업별로 묶여 있습니다. 각 페이지는 제목과 해당 페이지에서 다루는 내용을 설명하는 한 문장으로 시작합니다. 업데이트와 정보는 구분선 아래에 있습니다.

녹화와 텍스트 인식은 macOS 및 Windows에서만 사용할 수 있습니다. Linux beta는
해당 기능이 포함되지 않아 두 페이지 모두 숨겨집니다.

### 일반

시작 시 실행, 표시 언어, 앱 테마, CLI 설치/제거.

macOS에서는 이 페이지에 화면 녹화 및 접근성 권한 상태와 원클릭 시스템 설정 바로가기도 표시됩니다.

### 캡처

- **캡처 후**: `전체 화면 캡처 후 동작` (클립보드에 복사, 파일로 저장, 편집기 열기).
- **영역 선택기**: 커서 보조 표시(돋보기)와 바로가기 힌트.
- **자동 블러**: 자동 블러로 얼굴과 텍스트를 가릴 때 쓰는 흐림 유형과 강도.

### 핀 창

기본 불투명도, **마우스를 올리면 컨트롤 표시**, 불투명도와 확대/축소를 한 번 조정할 때의 변화량.

### 녹화

프레임 레이트, 기본 출력 형식, 미리보기 후 내보내기 동작, 오디오 소스/장치, 카운트다운.

### 저장

- 스크린샷 및 녹화 폴더와 파일명 형식 템플릿.
- 자동 저장과 ‘마지막 폴더 기억’: 켜면 Region, Pin, Beautify 및 보관함의 다른 이름으로 저장 대화 상자가 마지막으로 수동 이미지 저장에 성공한 폴더에서 열립니다. 자동 저장은 계속 스크린샷 폴더를 사용합니다.
- **워터마크**: 워터마크 이미지, 스크린샷/녹화 적용 여부, 불투명도, 크기, 여백, 위치 (미리보기 포함).
- **보관함**: 보관함에 유지할 스크린샷 수. 이보다 많아지면 가장 오래된 항목부터 보관함에서 제거되며, 저장한 파일은 그대로 남습니다.

### 텍스트 인식

OCR 언어 순서 및 인식 후 동작.

### 단축키

기능 카테고리별 중앙 집중식 단축키 편집기. 단축키마다 개별로 재설정할 수 있고, **모든 기본값 복원**으로 한 번에 모두 재설정합니다.

### 업데이트

현재 버전, 자동 확인 간격, 마지막 확인 상태, 수동 지금 확인.

### 정보

앱 이름, 버전, 저작권, 제작자, 웹사이트 링크.

## 설정 찾기 및 재설정

- 사이드바 상단의 **설정 검색**(`Ctrl+F`, macOS에서는 `Cmd+F`)으로 설정 이름, 섹션(예: "워터마크"), 페이지로 설정을 찾고, 동작 이름으로 단축키를 찾을 수 있습니다. `Up`/`Down`과 `Enter`로 결과를 열면 SnapTray가 해당 페이지로 이동해 그 설정까지 스크롤하고 잠시 강조 표시합니다. `Esc`를 누르면 검색이 지워집니다.
- 설정은 변경하는 즉시 저장됩니다. 설정이 기본값과 다르면 이름 왼쪽에 **재설정** 버튼이 나타나며, 해당 설정 하나만 되돌립니다. 단축키는 기존의 **재설정**과 **모든 기본값 복원**을 그대로 사용합니다. 언어, 테마, 로그인 시 시작, 입력 장치, 워터마크 이미지, OCR 언어처럼 시스템이나 사용자 본인의 선택에 따라 정해지는 설정에는 재설정 버튼이 없습니다.

## 권장 기본 프로필

- macOS/Windows에서 표준 튜토리얼은 30 FPS MP4 사용
- 스크린샷과 (지원되는 플랫폼의) 녹화를 위한 전용 폴더 지정
- 매일 자동 업데이트 확인 활성화
