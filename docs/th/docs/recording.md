การบันทึกหน้าจอใช้ได้เฉพาะบน macOS และ Windows เท่านั้น Linux beta ไม่รวมการบันทึก และ UI การบันทึกถูกซ่อนไว้

บน Windows แบ็กเอนด์ Windows Graphics Capture ซึ่งเป็นตัวเลือกเสริมจะไม่นับภาพใหม่ที่มาถึงหลังเฟรมภาพนิ่งที่ส่งซ้ำว่าเป็นเฟรมซ้ำเพียงเพราะการประทับเวลาอีกต่อไป โดยยังคงใช้ขีดจำกัดอัตราเฟรมที่เลือกไว้

## อ่านบทพูดขณะบันทึก

ในหน้าตั้งค่าการบันทึก ให้เลือกหน้าจอแสดงบทพูด พิมพ์หรือวางบทพูด แล้วเลือกอีกหน้าจอสำหรับบันทึก ต้องใช้โหมดขยายหน้าจอ ระหว่างบันทึกให้เลื่อนข้อความด้วยตนเองและใช้ A− หรือ A+ เพื่อปรับขนาดตัวอักษร เมื่อหยุดชั่วคราวตำแหน่งการอ่านจะคงเดิม หน้าต่างจะปิดเมื่อสิ้นสุดการบันทึกหรือเปลี่ยนการจัดวางหน้าจอ บน X11 การเปลี่ยนการจัดวางหน้าจออาจทำให้การบันทึกหยุดลงเพื่อป้องกันไม่ให้บทพูดติดไปในวิดีโอ บทพูดอยู่ในหน่วยความจำเฉพาะการบันทึกครั้งนี้ ใช้ได้โดยไม่ต้องต่ออินเทอร์เน็ตหรือใช้ไมโครโฟน

## กู้คืนการแก้ไขที่ยังไม่ได้บันทึก

ทั้งการบันทึกใหม่และโปรเจกต์เดิมจะบันทึกฉบับร่างลงเครื่องหลังหยุดแก้ไขประมาณ 750 มิลลิวินาที โดยรวมการครอบตัด ช่วงเวลา ส่วนที่ปิดบัง เสียง รูปลักษณ์ และการตั้งค่าการส่งออก การออกจากแอปตามปกติจะบันทึกการแก้ไขที่รออยู่ หากแอปหยุดทำงานระหว่างรอหรือเขียนไฟล์ การแก้ไขล่าสุดอาจสูญหาย

เมื่อเปิดอีกครั้ง แอปจะถามก่อนแสดงวิดีโอ เลือกกู้คืนเพื่อแก้ไขต่อ ทิ้งฉบับร่างเพื่อเปิดเวอร์ชันที่บันทึกล่าสุด หรือยกเลิกเพื่อเก็บฉบับร่าง หากฉบับร่างเสียหาย ไม่เข้ากัน หรือเป็นของวิดีโออื่น จะไม่สามารถกู้คืนได้ หากบันทึกไม่สำเร็จ ให้ตรวจสอบพื้นที่ว่างและสิทธิ์ของไฟล์แล้วลองอีกครั้ง

## จุดเริ่มต้นการบันทึก

- เมนูถาดระบบ: Record Screen
- ปุ่มลัดการบันทึก: กำหนดค่า Record Screen ใน Settings > Hotkeys

## วงจรชีวิตการบันทึก

1. เลือกหน้าจอที่ต้องการบันทึกเมื่อมีการแสดงผลหลายจอ
2. การบันทึกเริ่มทันทีบนหน้าจอที่เลือก
3. ใช้แถบควบคุมแบบลอยเพื่อตรวจสอบระยะเวลาและหยุดการบันทึก
4. คลิก Stop เพื่อส่งออก

## รูปแบบเอาต์พุต

| รูปแบบ | การใช้งานทั่วไป |
|---|---|
| MP4 (H.264) | บทช่วยสอน การบันทึกยาว |
| GIF | สาธิตวนซ้ำสั้น |
| WebP | คลิปเคลื่อนไหวขนาดเบา |

## ตัวเลือกเสียง

การจับเสียงใช้ได้สำหรับการบันทึก MP4 เมื่อแพลตฟอร์มและแหล่งสัญญาณปัจจุบันรองรับ:

- ไมโครโฟน
- เสียงระบบ
- การจับแบบผสม

GIF และ WebP ส่งออกแบบไม่มีเสียง

## การปรับคุณภาพ

เปิด Settings > Recording แล้วปรับเฟรมเรต คุณภาพ การนับถอยหลัง และพฤติกรรมการแสดงตัวอย่าง
