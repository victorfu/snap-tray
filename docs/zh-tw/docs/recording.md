錄影支援 macOS、Windows 與啟用錄影功能的 Linux X11 版本。Linux 使用系統 FFmpeg 函式庫與 PulseAudio（或 PipeWire 的 PulseAudio 相容服務）。

## 錄影入口

- 托盤選單：Record Screen
- 錄影快捷鍵：至 Settings > Hotkeys 設定 Record Screen

## 錄影生命週期

1. 多螢幕環境下，依提示選擇要錄製的螢幕。
2. 錄影會在選定螢幕上直接開始。
3. 透過浮動控制列查看時間、暫停或繼續，以及停止錄影。暫停時控制列會顯示「已暫停」，時間也會停止。Linux 錄影時會隱藏浮動控制列，請使用托盤選單暫停、繼續或停止。
4. 按 Stop 開啟預覽（關閉預覽時則直接儲存）。

錄影時，托盤選單也提供「暫停錄製／繼續錄製」，macOS 與 Windows 另有「顯示錄影控制列」，兩者都可在「設定 > 快捷鍵」指定快捷鍵。

在預覽視窗中，垃圾桶按鈕、**Esc** 與視窗的關閉按鈕都會先詢問才刪除錄影。在詢問畫面按 **Esc** 或 **Enter** 會保留錄影；按 **Tab** 可移到「捨棄」。正在框選裁切範圍時，**Esc** 只會取消裁切。

錄影期間，托盤或選單列圖示的角落會顯示狀態標記：準備或倒數時為圓環、錄影中為紅點、暫停時為暫停符號、影片收尾時為三個點。將游標移到圖示上，可查看目前狀態、已錄製時間（不含暫停）及正在錄製的螢幕。若托盤位於被錄製的螢幕上，圖示可能會出現在影片中。

## 裁切錄影

錄影一律擷取整個螢幕。若只想保留其中一部分，請在停止錄影後於預覽視窗中裁切：

1. 在預覽工具列中按一下 **裁切**。
2. 在影片上拖曳以畫出裁切範圍，再於範圍內拖曳可移動，或拖曳控點調整大小。邊緣會吸附到影片邊緣與中心線。將游標移到視窗上會亮起，點一下即可裁切成該視窗在影片目前時間點的範圍。
3. 按 **Enter** 套用，或按 **Esc** 取消。套用後的尺寸會顯示在影片左上角，按 ✕ 即可清除。
4. 另存為 MP4、GIF 或 WebP。匯出的 MP4 會保留音訊。

裁切時，時間軸下方那一列提供：

- **比例預設**：自由、原始、16:9、4:3、1:1、9:16。拖曳畫框、調整大小與點選視窗都會維持所選比例。
- **X、Y、W、H**：以影片像素表示的裁切範圍。輸入的數值會依編碼器需求調整為偶數並符合最小尺寸，畫框旁的尺寸標籤一律顯示實際會輸出的大小。
- **方向鍵** 每次移動 2 像素（按住 Shift 為 10 像素）。在欄位中輸入的按鍵只作用於該欄位；在欄位中按 **Esc** 只會還原欄位內容。

有修剪範圍時，可在時間軸下方以 `m:ss.mmm`（例如 `0:07.250`）輸入開始與結束時間。

每次套用的裁切與修剪都能復原（**Ctrl+Z**）與重做（**Ctrl+Shift+Z** 或 **Ctrl+Y**）。按 ⟲ 可回到未編輯的錄影（同樣可復原），按 ◧ 或 **\\** 可與原始畫面比較。時間軸下方會顯示原始與輸出的像素尺寸、保留的時長，以及所選格式是否有音訊。

## 輸出格式

| 格式 | 適用情境 |
|---|---|
| MP4 (H.264) | 長時教學、產品 Demo |
| GIF | 短循環示意 |
| WebP | 輕量動態片段 |

## 音訊選項

目前僅 MP4 錄影會在平台與音源支援時提供音訊：

- 麥克風
- 系統音訊
- 混合錄音

GIF 與 WebP 輸出不包含音訊。

### 錄影前檢查音訊

在「設定 > 錄影」開啟「錄製前顯示設定」後，每次錄影前都會出現簡短的設定畫面；有多個螢幕時，選擇螢幕的畫面也會一併顯示。畫面上可確認螢幕、麥克風與輸入裝置、系統音訊，以及輸出格式、預覽與倒數的摘要。變更會被儲存，之後的快速錄影會沿用。

按「測試麥克風」可查看即時輸入音量。只有在測試期間才會開啟麥克風；停止測試、開始錄影或取消時就會釋放，也不會播放聲音。無聲只會讓音量條保持空白，不會阻止錄影。

若已儲存的麥克風被拔除，清單會標示「未連接」，錄影時會改用預設麥克風並提示。

### 錄影中的音訊狀態

錄影期間，托盤或選單列的提示會分別列出麥克風與系統音訊的狀態：正在錄製、正在啟動、關閉、權限遭拒、找不到裝置、無法使用，或 GIF/WebP 不支援。若錄影中途降級（例如只剩系統音訊），通知消失後提示仍會持續顯示。

## 品質調校

在 Settings > Recording 可調整 FPS、畫質、倒數計時與預覽行為。

畫質滑桿決定的是儲存後影片的畫質。開啟預覽時,錄影本身會以高畫質擷取,讓裁剪與修剪不會損失細節;儲存時再轉成所選畫質,若檔案本來就夠小則直接保留原檔。若暫存錄影所在的磁碟剩餘空間不足約十分鐘的高畫質錄影,SnapTray 會改以所選畫質錄製並顯示警告。關閉預覽時,錄影會直接以所選畫質寫入。
