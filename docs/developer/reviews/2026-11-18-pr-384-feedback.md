## Compatibility decisions

- A legacy timeline part without `keepSound` retains silence at non-1× speeds. Newly created parts keep sound by default. Normal speed always restores normal sound.
- Local captions (#334) remain deferred.

The canonical application build passed again. All six affected preview suites (Timeline, Pointer, Crop, Zoom, Export and Discard) passed in 24.63 seconds, including the eight new cases. ## Fourth round: macOS repaint probe

macOS [job 134542017424](https://github.com/victorfu/snap-tray/actions/runs/44226858273/job/134542017424) passed 262/263 suites, including the keyboard tests. The OCR repaint fixture still failed its final pixel equality assertion. Its probe copied the entire sample area after every paint, including events that painted elsewhere. [Qt 6.12's Cocoa implementation](https://github.com/qt/qtbase/blob/6.12/src/plugins/platforms/cocoa/qcocoabackingstore.mm#L489-L508) only guarantees the painted region's contents before the back buffer is finalized at flush.

The probe now accumulates only freshly painted pixels into an owned sample. It waits for complete initial coverage and preserves untouched pixels when another back buffer is used. A controlled stale-buffer regression fails before the change at normal and Retina scale; afterwards it verifies unrelated paints, partial updates and erasure split across two paint regions. Both real spinner tests retain their exact dirty-region and pixel-equality assertions.

The full OCR repaint suite passes, as do ten consecutive runs at 2× scale. The canonical application build and `git diff --check` pass. Review covered pixel coordinates, DPR conversion, image copy ownership and partial coverage; no further issue remained. Native macOS CI is still needed to confirm the corrected probe on Cocoa.
