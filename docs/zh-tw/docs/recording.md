錄影支援 macOS、Windows 與啟用錄影功能的 Linux X11 版本。Linux 使用系統 FFmpeg 函式庫與 PulseAudio（或 PipeWire 的 PulseAudio 相容服務）。

## 錄影入口

- 托盤選單：Record Screen
- 錄影快捷鍵：至 Settings > Hotkeys 設定 Record Screen

## 錄影生命週期

1. 多螢幕環境下，依提示選擇要錄製的螢幕。
2. 錄影會在選定螢幕上直接開始。
3. 透過浮動控制列查看時間並停止錄影。Linux 錄影時會隱藏浮動控制列，請使用托盤選單暫停、繼續或停止。
4. 按 Stop 匯出檔案。

## 裁切錄影

錄影一律擷取整個螢幕。若只想保留其中一部分，請在停止錄影後於預覽視窗中裁切：

1. 在預覽工具列中按一下 **裁切**。
2. 在影片上拖曳以畫出裁切範圍，再於範圍內拖曳可移動，或拖曳控點調整大小。邊緣會吸附到影片邊緣與中心線。將游標移到視窗上會亮起，點一下即可裁切成該視窗在影片目前時間點的範圍。
3. 按 **Enter** 套用，或按 **Esc** 取消。套用後的尺寸會顯示在影片左上角，按 ✕ 即可清除。
4. 另存為 MP4、GIF 或 WebP。匯出的 MP4 會保留音訊。

## 輸出格式

| 格式 | 適用情境 |
|---|---|
| MP4 (H.264) | 長時教學、產品 Demo |
| GIF | 短循環示意 |
| WebP | 輕量動態片段 |

## 音訊選項

目前僅 MP4 錄影會在平台與音源支援時提供音訊：

- 麥克風
- 系統音訊
- 混合錄音

GIF 與 WebP 輸出不包含音訊。

## 品質調校

在 Settings > Recording 可調整 FPS、畫質、倒數計時與預覽行為。

畫質滑桿決定的是儲存後影片的畫質。開啟預覽時,錄影本身會以高畫質擷取,讓裁剪與修剪不會損失細節;儲存時再轉成所選畫質,若檔案本來就夠小則直接保留原檔。若暫存錄影所在的磁碟剩餘空間不足約十分鐘的高畫質錄影,SnapTray 會改以所選畫質錄製並顯示警告。關閉預覽時,錄影會直接以所選畫質寫入。

## 從錄影產生長截圖

錄影時手動捲動單一垂直內容區域。在錄影預覽按「製作長截圖」，系統會暫停播放，沿用目前的時間範圍與裁切區域自動分析；尚未設定時使用整段錄影與全畫面。取消分析會保留錄影。

分析完成後會推薦一個範圍，顯示來源的起始與結束預覽、時間及預計圖片數。按「產生長截圖」只產生所選內容。無法完整拼接時，畫面會明確說明只包含部分內容；可展開「其他可用範圍」改選一個結果。不同片段不會強行接合，缺口也不會補白後假裝連續。

「調整分析範圍」使用既有的裁切與時間控制。「重新分析」確認變更；「取消」還原先前設定與推薦。拖曳控制項不會反覆啟動分析。

- **儲存 PNG**：儲存所選內容。超過 30,000 像素高時，依原始解析度分成多張有序號的圖片，分析頁會事先告知數量。不覆寫既有檔案；同一目的地重試時不會重複儲存成功的圖片。
- **複製**：複製目前圖片的原始像素。
- **更多…**：提供目前圖片的「釘選」與「在釘選中標註」。標註成品請從釘選視窗儲存。
- **選擇內容**：返回推薦頁；「錄影預覽」返回影片。關閉預覽前仍可使用來源錄影。

結果預設符合視窗寬度，小圖不會強制放大。捲動閱讀，使用 Ctrl＋滾輪縮放、Ctrl＋0 重設。若有接縫需要確認，只顯示一則摘要，按「查看」逐處檢查。標記只顯示於預覽，不會寫入儲存或複製的圖片。固定頁首與靜態側欄由系統處理，不再提供獨立的圖片列編輯器。

沒有可用範圍時，可縮小到單一內容區域，或重新錄製並緩慢捲動。靜止錄影不會被當成成功長截圖。超大輸出或過長範圍可能需要縮小裁切或縮短錄影。此功能處理垂直捲動，可用性取決於平台的離線影片讀取支援；尚未完成 5K／6K 錄影驗證。
