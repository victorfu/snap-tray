## ツールカテゴリ

### 描画

- ペン
- マーカー
- 矢印（単線とポリライン モード）
- 図形（長方形/楕円）

### マークアップとガイダンス

- テキスト
- ステップバッジ
- 絵文字スタンプ

### プライバシーと修正

- モザイク
- 消しゴム

## 編集ワークフロー

1. まず大まかな注釈を描きます。
2. 色と幅をグローバルに調整します。
3. テキストとステップバッジを追加して手順を示します。
4. 機密部分にモザイクを適用します。
5. エクスポート前に元に戻す/やり直しを使います。

## ベストプラクティス

- 重要な箇所には 1 色のアクセントカラーを使います。
- マーカーは強調に使い、密なテキストには使わないようにしましょう。
- 手順のスクリーンショットにはステップバッジを優先して使います。

## 美化（Beautify）

ピンツールバーの **美化** は、スクリーンショットを背景の上に配置し、そのまま共有できる見た目に仕上げます。

- **スタイル** は余白、角丸、影をまとめて設定します：**コンパクト**、**標準**（デフォルト）、**ゆったり**、**フラット**（影なし、角丸なし）。選択中のスタイルには枠が付き、自分で調整すると **カスタム** と表示されます。
- **背景** には名前付きのグラデーションが 8 種類あります。スタイルを変えても背景はそのまま、背景を変えてもスタイルはそのままです。
- **カスタマイズ** で詳細を開きます：背景の種類（単色、線形グラデーション、放射状グラデーション）、色、余白、角丸、影、影のぼかし、枠線、アスペクト比。
- **スタイルを保存…** は、現在の見た目一式（背景、余白、角丸、影、枠線、アスペクト比）を好きな名前で保存します。サイズはスクリーンショットの短辺に対する比率で保存されるため、小さな画像でも大きな画像でも同じ見た目になります。保存したスタイルは録画エディタの **キャンバス** と共有され、どちらで保存しても両方で使えます。この変更より前に保存したスタイルは、短辺 1440 px の画像で見た目が変わりません。保存したスタイルは組み込みスタイルの下に並び、クリックで適用、**✎**（キーボードフォーカスがあるときは `F2`）で名前を変更、**×**（または `Delete`）で削除できます。保存したスタイル同士で同じ名前は使えません。既存の名前で保存するとそのスタイルが更新されます。最大 8 個まで保存できます。
- **コピー** または **保存** すると、その見た目が次回も使われます。

録画エディターの **キャンバス** も同じグラデーションと同じ名前（背景、余白、角丸、影、アスペクト比）を使います。

## エクスポートアクション

- `Enter` で結果をピン留め
- `Ctrl/Cmd + C` でコピー
- `Ctrl/Cmd + S` で保存
