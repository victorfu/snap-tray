## 개요

SnapTray는 로컬 우선의 스크린샷·주석 앱입니다. 녹화 기능은 macOS와 Windows에서만 지원됩니다. Linux beta는 스크린샷과 주석만 지원합니다. 네트워크 연결은 선택적 업데이트 확인이 실행될 때만 이루어집니다. 저희는 개인정보 보호와 투명한 운영을 중요하게 생각합니다.

**핵심 요약:** SnapTray는 로컬 우선으로 동작하며 원격 분석·추적·분석 기능이 일체 없습니다. 네트워크 통신은 선택적 업데이트 확인(버전 문자열만 전송)에만 한정됩니다.

이 방침은 SnapTray 데스크톱 앱에 적용됩니다. snaptray.cc 웹사이트는 [웹사이트(snaptray.cc)](#website) 항목을 참고하세요.

## 데이터 수집

**어떠한 데이터도 수집하지 않습니다.** 구체적으로:

- 원격 분석 또는 사용 통계 분석을 수행하지 않습니다
- 외부 서버에 충돌 보고서를 전송하지 않습니다
- 사용자를 추적하거나 고유 식별자를 생성하지 않습니다

## 데이터 저장

SnapTray가 사용하거나 생성하는 모든 데이터는 사용자 기기에 로컬로 저장됩니다:

| 데이터 유형 | 저장 위치 | 용도 |
|------------|----------|------|
| 스크린샷 | 사용자 지정 폴더(기본값: 사진) | 캡처한 이미지 저장 |
| 녹화 | 사용자 지정 폴더(기본값: 다운로드) | macOS와 Windows 화면 녹화 저장. Linux beta는 녹화 기능 미포함 |
| 설정 | OS 설정 저장소* | 환경설정 저장 |

*설정 저장 위치:
- **macOS:** `~/Library/Preferences/cc.snaptray.plist`
- **Windows:** `HKEY_CURRENT_USER\Software\SnapTray`
- **Linux beta:** Qt/Linux 사용자 설정 저장소(일반적으로 `~/.config/<organization>/<application>.conf`)
- macOS에서는 `cc.snaptray` 이전 형식의 환경설정 파일을 정리할 때 가져오지 않고 바로 삭제합니다. Windows의 이전 설정은 정리 전에 마이그레이션됩니다.

## 권한

SnapTray는 기능에 따라 시스템 권한을 요청합니다:

### macOS

| 권한 | 용도 |
|------|------|
| Screen Recording | 스크린샷 및 녹화 핵심 기능 |
| Accessibility | 스마트 캡처를 위한 창 감지 |

### Windows

| 권한 | 용도 |
|------|------|
| Full Trust | DXGI 화면 캡처, WASAPI 오디오 캡처, OCR 기능에 필요 |

**선택적 권한:**
- 마이크 접근은 오디오 녹화를 선택한 경우에만 요청됩니다.

## 네트워크 통신

SnapTray는 선택적 업데이트 확인을 위해서만 연결하며 스크린샷을 업로드하지 않습니다.

### 업데이트 확인

SnapTray는 새 릴리스를 `api.github.com`에서 확인합니다. 이 기능은 기본으로 활성화되어 있으며 설정에서 비활성화할 수 있습니다. 앱 버전 문자열만 전송됩니다. 개인 정보, 사용 데이터, 기기 식별자는 일체 전송되지 않습니다. 스토어 설치(Microsoft Store, Mac App Store 등)의 경우 업데이트 확인을 건너뜁니다.

### SnapTray가 하지 않는 것

- 추적 SDK 또는 분석 도구를 포함하지 않습니다
- 쿠키 또는 유사 기술을 사용하지 않습니다
- 원격 분석 또는 충돌 보고서를 전송하지 않습니다

## 웹사이트(snaptray.cc) {#website}

이 항목은 snaptray.cc 웹사이트에만 적용되며, 위 내용은 바뀌지 않습니다. SnapTray 앱은 여전히 어떠한 데이터도 수집하지 않습니다.

웹사이트는 분석 도구를 사용하기 전에 먼저 동의를 묻습니다. 웹사이트 분석 안내에서 **허용**을 선택한 경우에만 방문 수와 다운로드 관심도를 집계하기 위해 Google 애널리틱스 4(Google 제공)를 불러옵니다. **거부**를 선택하거나, 안내에 응답하지 않거나, 브라우저가 Global Privacy Control 또는 Do Not Track 신호를 보내는 경우 Google 애널리틱스를 불러오지 않습니다.

허용한 경우 전송되는 정보:

- 페이지 조회: 쿼리 문자열을 제외한 페이지 경로와 페이지 언어
- 유입된 웹사이트의 도메인(전체 주소는 전송하지 않음)
- 접속한 링크의 캠페인 태그(`utm_source`, `utm_medium`, `utm_campaign`, `utm_content`). 웹사이트에 미리 정의된 값과 일치할 때만 전송하며, 그 밖의 값은 "other"로 기록합니다
- 다운로드, Microsoft Store, GitHub 링크 클릭: 플랫폼, 릴리스 버전, 페이지 내 링크 위치

서비스 제공을 위해 Google은 IP 주소와 브라우저 정보도 받습니다. Google 애널리틱스 4는 IP 주소를 기록하거나 저장하지 않습니다. Google 신호와 광고 개인 최적화는 꺼져 있습니다. 양식 입력, 전체 쿼리 문자열, 이메일 주소, SnapTray 앱의 데이터는 전송하지 않습니다.

쿠키 및 브라우저 저장소:

| 이름 | 유형 | 설정 시점 | 용도 | 보관 기간 |
|------|------|-----------|------|-----------|
| `_ga`, `_ga_<ID>` | 쿠키(Google 애널리틱스) | 분석을 허용한 후 | 재방문과 세션 구분 | 최대 2년 또는 거부할 때까지 |
| `snaptray.analyticsConsent` | 로컬 저장소 | 허용 또는 거부를 선택할 때 | 선택 내용 기억 | 12개월 |
| `snaptray.attribution` | 세션 저장소 | 분석을 허용한 후 | 둘러보는 동안 유입 캠페인 유지 | 탭을 닫거나 30분 동안 페이지 조회가 없을 때까지 |

Google 애널리틱스의 분석 데이터는 2개월간 보관한 뒤 삭제됩니다. 집계된 보고서(예: 캠페인별 다운로드 클릭 수)는 더 오래 보관될 수 있습니다.

선택을 바꾸려면 각 페이지 하단의 **분석 설정**을 사용하세요. 허용한 뒤 거부하면 분석이 중단되고, 해당 브라우저에 저장된 이 웹사이트의 Google 애널리틱스 쿠키가 삭제됩니다.

분석 수치는 추정치입니다. 광고 차단기, 동의하지 않은 방문, 네트워크 문제로 인해 일부 방문은 집계되지 않습니다.
