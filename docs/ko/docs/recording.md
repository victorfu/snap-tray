녹화는 macOS 및 Windows에서만 사용 가능합니다. Linux beta는 녹화를 포함하지 않으며,
녹화 관련 UI가 숨겨져 있습니다.

Windows에서 선택적으로 사용하는 Windows Graphics Capture 백엔드는 반복된 정지 프레임 뒤에 도착한 새 화면을 타임스탬프 때문에 중복 프레임으로 집계하지 않습니다. 선택한 프레임 속도 제한은 계속 적용됩니다.

## 녹화 중 대본 읽기

녹화 설정에서 프롬프터 화면을 선택하고 대본을 입력하거나 붙여 넣은 후 다른 화면을 녹화 대상으로 선택하세요. 두 화면은 확장 모드여야 합니다. 녹화 중에는 직접 스크롤하거나 A− 및 A+로 글자 크기를 조절할 수 있습니다. 일시 정지하면 읽던 위치가 유지되고, 녹화를 종료하거나 화면 배치를 변경하면 창이 닫힙니다. X11에서는 대본이 녹화되는 것을 막기 위해 화면 배치 변경 시 녹화도 중단될 수 있습니다. 대본은 이번 녹화 동안만 메모리에 보관되며 인터넷이나 마이크가 필요하지 않습니다.

## 저장하지 않은 편집 내용 복구

새 녹화와 기존 프로젝트에서 편집을 멈춘 후 약 750밀리초가 지나면 자르기, 구간, 마스크, 오디오, 모양 및 내보내기 설정을 로컬 초안에 저장합니다. 정상 종료 시 대기 중인 변경 사항도 저장합니다. 대기 또는 쓰기 도중 강제 종료되면 최근 변경 사항이 사라질 수 있습니다.

다시 열면 영상을 표시하기 전에 복구 여부를 묻습니다. 복원을 선택하면 편집을 계속하고, 초안 버리기를 선택하면 마지막으로 저장한 버전을 엽니다. 취소하면 초안이 보관됩니다. 손상되거나 호환되지 않거나 다른 녹화에 속한 초안은 적용되지 않습니다. 저장에 실패하면 여유 공간과 파일 권한을 확인한 뒤 다시 시도하세요.

## 녹화 진입점

- 트레이 메뉴: 화면 녹화
- 녹화 단축키: 설정 > 단축키에서 화면 녹화 구성

## 녹화 라이프사이클

1. 다중 디스플레이 설정에서 프롬프트가 표시될 때 녹화할 화면을 선택합니다.
2. 선택한 화면에서 즉시 녹화가 시작됩니다.
3. 플로팅 컨트롤 바를 사용하여 녹화 시간을 모니터링하고 중지합니다.
4. 중지를 클릭하여 내보냅니다.

## 출력 형식

| 형식 | 주요 용도 |
|---|---|
| MP4 (H.264) | 튜토리얼, 긴 녹화 |
| GIF | 짧은 반복 데모 |
| WebP | 경량 애니메이션 클립 |

## 오디오 옵션

MP4 녹화에서 현재 플랫폼과 소스가 지원하는 경우 오디오 캡처를 사용할 수 있습니다.

- 마이크
- 시스템 오디오
- 혼합 캡처

GIF와 WebP 내보내기는 소리가 없습니다.

## 품질 조정

설정 > 녹화를 열어 프레임 레이트, 품질, 카운트다운, 미리보기 동작을 조정하세요.
