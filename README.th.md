SnapTray คือแอปสกรีนช็อตและมาร์กอัปที่สร้างด้วย Qt 6 รองรับ macOS, Windows และ Ubuntu 22.04 X11 beta ออกแบบมาเพื่อเวิร์กโฟลว์บนเดสก์ท็อปที่รวดเร็ว: จับภาพเฉพาะส่วน อธิบายได้ทันที และเก็บภาพอ้างอิงไว้บนหน้าจอ การบันทึกหน้าจอและ OCR ใช้ได้เฉพาะ macOS/Windows โดยจะถูกซ่อนและไม่รวมอยู่ใน Linux beta

## ทำไมต้อง SnapTray

- จับภาพได้รวดเร็วด้วยการเลือกแบบแว่นขยาย การตรวจจับหน้าต่าง การจับภาพหลายส่วน การรวมเคอร์เซอร์ และการดูดสี
- มาร์กอัปได้ทันทีด้วยลูกศร มาร์กเกอร์ รูปทรง ข้อความ โมเสก แบดจ์ขั้นตอน อีโมจิ QR Code Scan และเบลออัตโนมัติ ส่วน OCR ใช้ได้เฉพาะ macOS/Windows
- ปักหมุดสกรีนช็อตไว้เหนือหน้าต่างอื่น เพื่อให้ภาพอ้างอิงมองเห็นได้ตลอดขณะทำงาน
- บน macOS/Windows บันทึกหน้าจอทั้งจอจากเมนูถาดระบบหรือปุ่มลัดการบันทึก โดยเริ่มได้ทันทีเมื่อมีจอเดียว และเลือกหน้าจอเมื่อมีหลายจอ
- เรียกใช้ขั้นตอนที่ทำซ้ำได้จากปุ่มลัดส่วนกลาง เมนูถาดระบบ หรือ CLI
- Linux beta: Ubuntu 22.04 X11 AppImage โดยจะไม่แสดงการบันทึกหน้าจอและ OCR

## ออกแบบมาเพื่องานจริง

### จับภาพและมาร์กอัปในขั้นตอนเดียว

กด `F2` ลากเลือกพื้นที่ แล้วคัดลอก บันทึก ปักหมุด หรือเบลอได้จากแถบเครื่องมือเดียวกัน บน macOS/Windows ยังใช้ OCR ได้จากที่นั่นด้วย

> **หมายเหตุ:** การแชร์รูปภาพ (อัปโหลดเพื่อสร้าง URL สำหรับแชร์) ถูกปิดใช้งานอยู่ในขณะนี้ ปุ่มแชร์ถูกซ่อนจากแถบเครื่องมือของการจับภาพและหน้าต่างปักหมุด จึงไม่สามารถเรียกใช้จากส่วนติดต่อผู้ใช้ได้ โค้ดของฟีเจอร์แชร์ยังคงถูกเก็บไว้โดยตั้งใจ เพื่อให้เปิดใช้งานใหม่ในบิลด์ถัดไปได้โดยไม่ต้องเขียนใหม่

### วาดบนเดสก์ท็อปได้โดยตรง

ใช้ `Ctrl+F2 / Cmd+F2` เพื่อเปิดสกรีนแคนวาสสำหรับการสาธิต การอธิบายขั้นตอน การนำเสนอ และการอธิบายแบบสด

### เก็บภาพอ้างอิงไว้ในที่ที่ต้องการ

ภาพที่ปักหมุดจะอยู่เหนือแอปอื่นเสมอ และรองรับการซูม ความโปร่งใส การหมุน การพลิก การรวม/จัดวาง และการมาร์กอัปในตัว

### บันทึกเฉพาะสิ่งที่สำคัญ

บน macOS/Windows เริ่มจากเมนูถาดระบบหรือปุ่มลัดการบันทึก เลือกหน้าจอเมื่อจำเป็น จากนั้นใช้แถบควบคุมแบบลอยเพื่อดูระยะเวลาและหยุดการบันทึก

## สำหรับนักพัฒนา

หากต้องการบิลด์ SnapTray จากซอร์สโค้ดหรือร่วมพัฒนาโค้ดเบส เริ่มที่ [เอกสารสำหรับนักพัฒนา](docs/developer/index.md) (ภาษาอังกฤษ)

จุดเริ่มต้นอย่างรวดเร็ว:

```bash
# macOS/Linux beta
./scripts/build.sh
./scripts/run-tests.sh
```

```batch
REM Windows
scripts\build.bat
scripts\run-tests.bat
```
