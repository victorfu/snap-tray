錄影支援 macOS、Windows 與啟用錄影功能的 Linux X11 版本。Linux 使用系統 FFmpeg 函式庫與 PulseAudio（或 PipeWire 的 PulseAudio 相容服務）。

## 錄影入口

- 托盤選單：Record Screen
- 錄影快捷鍵：至 Settings > Hotkeys 設定 Record Screen

## 錄影生命週期

1. 多螢幕環境下，依提示選擇要錄製的螢幕。
2. 錄影會在選定螢幕上直接開始。
3. 透過浮動控制列查看時間並停止錄影。Linux 錄影時會隱藏浮動控制列，請使用托盤選單暫停、繼續或停止。
4. 按 Stop 匯出檔案。

## 裁切錄影

錄影一律擷取整個螢幕。若只想保留其中一部分，請在停止錄影後於預覽視窗中裁切：

1. 在預覽工具列中按一下 **裁切**。
2. 在影片上拖曳以畫出裁切範圍，再於範圍內拖曳可移動，或拖曳控點調整大小。邊緣會吸附到影片邊緣與中心線。將游標移到視窗上會亮起，點一下即可裁切成該視窗在影片目前時間點的範圍。
3. 按 **Enter** 套用，或按 **Esc** 取消。套用後的尺寸會顯示在影片左上角，按 ✕ 即可清除。
4. 另存為 MP4、GIF 或 WebP。匯出的 MP4 會保留音訊。

## 輸出格式

| 格式 | 適用情境 |
|---|---|
| MP4 (H.264) | 長時教學、產品 Demo |
| GIF | 短循環示意 |
| WebP | 輕量動態片段 |

## 音訊選項

目前僅 MP4 錄影會在平台與音源支援時提供音訊：

- 麥克風
- 系統音訊
- 混合錄音

GIF 與 WebP 輸出不包含音訊。

## 品質調校

在 Settings > Recording 可調整 FPS、畫質、倒數計時與預覽行為。

畫質滑桿決定的是儲存後影片的畫質。開啟預覽時,錄影本身會以高畫質擷取,讓裁剪與修剪不會損失細節;儲存時再轉成所選畫質,若檔案本來就夠小則直接保留原檔。若暫存錄影所在的磁碟剩餘空間不足約十分鐘的高畫質錄影,SnapTray 會改以所選畫質錄製並顯示警告。關閉預覽時,錄影會直接以所選畫質寫入。

## 從錄影產生長截圖

在 macOS 或 Windows 錄影時，手動捲動單一垂直內容區域。在錄影預覽中選擇需要的時間範圍，並裁切至捲動區域（可使用視窗吸附），選擇「長截圖」後按產生按鈕。分析及繪製期間會暫停播放；取消作業會保留錄影。

分享前請檢查結果。畫面會顯示自動裁邊、信心較低及未接合的區段。點選有來源時間的標記可返回影片對應位置；無法定位的內容缺口不會提供虛假的跳轉位置。無法確定的接縫不會猜補；完全沒有可靠內容時會顯示錯誤。

- **儲存 PNG**：儲存全部分張，必要時附加序號。既有檔案不會被覆寫，名稱衝突會改用唯一名稱。同一目的地重試失敗分張時，不會重複儲存已成功的分張。
- **複製／釘選**：以原始解析度輸出目前選取的一張。
- **返回**：回到影片調整裁切、時間範圍，或另存影片。
- 預設排除固定標頭，可按「保留固定標頭」重新產生。

超過 30,000 像素高時會自動分張。三種輸出操作都保留原錄影與預覽；關閉預覽仍會丟棄暫存錄影。預覽僅載入可見的圖片區塊，避免超大紋理；範圍或輸出過大時會明確拒絕，請縮短時間或縮小裁切區域。

此功能僅支援垂直捲動，Linux beta 不提供。目前尚未完成 5K／6K 螢幕的錄影驗證。

### 獨立區段與成品修整

無法接合的可靠內容會各自輸出，按該區段首次出現在錄影中的時間排序，不猜測區段之間在原頁面的位置。結果會分別標示「區段」及「分張」：同一區段超過 30,000 像素高時仍會分張。沒有可靠配對的孤立影格仍列為未接合片段。儲存 PNG 會輸出所有區段，檔名使用 `-s01`，需要分張時則為 `-s01-p001`。

按「修整圖片」，在圖片上垂直拖曳以選取橫向範圍。「保留選取」裁去範圍上方與下方的內容；「刪除選取」移除該橫向範圍，將剩餘列接起來。修整只影響目前分張。每張保留 32 步復原／重做（Ctrl／Cmd+Z、Ctrl／Cmd+Shift+Z，或 Ctrl+Y）；「重設圖片」始終可以還原最初產生的圖片。不能刪除整張圖片，問題標記也會跟隨保留下來的像素調整。

「返回」可回到錄影，再以「檢視結果」回到修整中的圖片。變更錄影裁切、時間範圍或重新產生會重設成品修整。儲存修整後的版本會建立新檔，保留先前匯出。「在釘選視窗標註」會開啟目前修整後的分張並顯示既有標註工具列；請在該釘選視窗儲存標註成品，標註不會回寫其他分張或錄影預覽中的圖片。
