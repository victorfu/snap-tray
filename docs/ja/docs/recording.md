録画は macOS と Windows でのみ利用可能です。Linux beta には録画機能は含まれておらず、
録画 UI は非表示になっています。

Windows では、任意で使用する Windows Graphics Capture バックエンドで、繰り返された静止フレームの後に届く新しい映像が、タイムスタンプを理由に重複フレームとして数えられなくなりました。選択したフレームレートの制限は引き続き適用されます。

## 録画中に原稿を読む

録画設定で「プロンプターの画面」を選び、原稿を入力または貼り付けて、録画には別の画面を選びます。拡張デスクトップが必要です。録画中は手動でスクロールし、A− と A+ で文字サイズを変更できます。一時停止すると位置が保持され、停止や画面配置の変更で閉じます。X11 では画面配置を変更すると、原稿の映り込みを防ぐため録画も中断されることがあります。原稿はその録画中だけメモリに保持されます。マイクやインターネット接続は不要です。

## 未保存の編集を復元する

新規録画と既存のプロジェクトでは、編集操作が止まって約 750 ミリ秒後に下書きを保存します。切り抜き、区間、マスク、音声、外観、書き出し設定が対象です。正常終了時には保留中の編集も保存します。待機中や書き込み中の異常終了では最新の変更を失う場合があります。

録画を開き直すと、映像を表示する前に復元するか確認します。「復元」で編集を再開し、「下書きを破棄」で最後に保存した版を開きます。「キャンセル」では下書きが残ります。破損、非対応の版、録画の不一致がある下書きは適用されません。書き込みに失敗した場合は空き容量と権限を確認して再試行してください。

## 録画の開始方法

- トレイメニュー：画面を録画
- 録画ホットキー：設定 > ホットキーで「画面を録画」を設定

## 録画のライフサイクル

1. マルチディスプレイ環境では、録画する画面を選択します。
2. 選択した画面で録画がすぐに開始されます。
3. フローティングコントロールバーで録画時間を確認し、録画を停止します。
4. 停止をクリックしてエクスポートします。

## 出力フォーマット

| フォーマット | 典型的な用途 |
|---|---|
| MP4（H.264） | チュートリアル、長い録画 |
| GIF | 短いループデモ |
| WebP | 軽量なアニメーションスニペット |

## 音声オプション

現在のプラットフォームとソースでサポートされている場合、MP4 録画で音声キャプチャが利用可能です：

- マイク
- システム音声
- ミックスキャプチャ

GIF と WebP のエクスポートは無音です。

## 品質の調整

設定 > 録画 を開いて、フレームレート、品質、カウントダウン、プレビュー動作を調整します。
