## 概要

SnapTray はローカル優先のスクリーンショット・注釈アプリです。録画機能は macOS と Windows のみ対応しています。Linux beta はスクリーンショットと注釈のみサポートします。ネットワーク接続は、任意のアップデート確認が動作するときに限られます。プライバシーの保護と透明性のある運用を重視しています。

**要点：** SnapTray はローカル優先で動作し、テレメトリ・追跡・分析は一切ありません。ネットワーク通信は、任意のアップデート確認（バージョン文字列のみ）に限定されます。

本ポリシーは SnapTray デスクトップアプリを対象としています。snaptray.cc ウェブサイトについては[ウェブサイト（snaptray.cc）](#website)をご覧ください。

## データ収集

**データは一切収集しません。** 具体的には：

- テレメトリや利用状況の分析は行いません
- クラッシュレポートを外部サーバーに送信しません
- ユーザーの追跡や固有識別子の作成は行いません

## データの保存

SnapTray が使用・生成するすべてのデータはお使いのデバイス上にローカル保存されます：

| データの種類 | 保存場所 | 目的 |
|-------------|----------|------|
| スクリーンショット | ユーザー指定フォルダ（既定：ピクチャ） | キャプチャした画像の保存 |
| 録画 | ユーザー指定フォルダ（既定：ダウンロード） | macOS と Windows の画面録画を保存。Linux beta は録画機能を含みません |
| 設定 | OS の設定ストレージ* | 各種設定の保存 |

*設定の保存場所：
- **macOS:** `~/Library/Preferences/cc.snaptray.plist`
- **Windows:** `HKEY_CURRENT_USER\Software\SnapTray`
- **Linux beta:** Qt/Linux ユーザー設定ストレージ（通常 `~/.config/<organization>/<application>.conf`）
- macOS では、`cc.snaptray` より前の旧形式の設定ファイルはクリーンアップ時に直接削除され、インポートされません。Windows の旧設定はクリーンアップ前に移行されます。

## 権限

SnapTray は機能に応じてシステム権限を要求します：

### macOS

| 権限 | 用途 |
|------|------|
| Screen Recording | スクリーンショットと録画のコア機能 |
| Accessibility | スマートキャプチャ機能のためのウィンドウ検出 |

### Windows

| 権限 | 用途 |
|------|------|
| Full Trust | DXGI 画面キャプチャ、WASAPI 音声キャプチャ、OCR 機能に必要 |

**任意の権限：**
- マイクへのアクセスは、音声録音を選択した場合にのみ要求されます。

## ネットワーク通信

SnapTray は任意のアップデート確認のために接続します。スクリーンショットはアップロードしません。

### アップデート確認

SnapTray は新しいリリースを `api.github.com` で確認します。この確認はデフォルトで有効になっており、設定から無効にできます。送信されるのはアプリのバージョン文字列のみです。個人情報・利用状況・デバイス識別子は一切送信されません。ストアインストール（Microsoft Store、Mac App Store 等）の場合はアップデート確認をスキップします。

### SnapTray が行わないこと

- 追跡 SDK や分析ツールを含みません
- Cookie や類似技術を使用しません
- テレメトリやクラッシュレポートを送信しません

## ウェブサイト（snaptray.cc） {#website}

このセクションは snaptray.cc ウェブサイトのみを対象とし、上記の内容は変わりません。SnapTray アプリは引き続きデータを一切収集しません。

ウェブサイトは解析を使う前に確認します。ウェブサイトの解析に関する案内で**許可する**を選んだ場合にのみ、訪問数とダウンロードへの関心を計測するため Google アナリティクス 4（Google 提供）を読み込みます。**拒否する**を選んだ場合、案内に応答しない場合、またはブラウザが Global Privacy Control や Do Not Track を送信している場合、Google アナリティクスは読み込まれません。

許可した場合に送信される情報：

- ページビュー：クエリ文字列を除いたページのパスと、ページの言語
- 参照元サイトのドメイン（完全な URL は送信しません）
- アクセスしたリンクのキャンペーンタグ（`utm_source`、`utm_medium`、`utm_campaign`、`utm_content`）。ウェブサイトがあらかじめ定めた値に一致する場合のみ送信し、それ以外は「other」として記録します
- ダウンロード、Microsoft Store、GitHub へのリンクのクリック：プラットフォーム、リリースバージョン、ページ内のリンクの位置

サービス提供のため、Google はお使いの IP アドレスとブラウザ情報も受け取ります。Google アナリティクス 4 は IP アドレスを記録・保存しません。Google シグナルと広告のパーソナライズは無効にしています。フォーム入力、完全なクエリ文字列、メールアドレス、SnapTray アプリのデータは送信しません。

Cookie とブラウザストレージ：

| 名前 | 種類 | 設定されるタイミング | 目的 | 保存期間 |
|------|------|----------------------|------|----------|
| `_ga`、`_ga_<ID>` | Cookie（Google アナリティクス） | 解析を許可した後 | 再訪問とセッションの区別 | 最長 2 年、または拒否するまで |
| `snaptray.analyticsConsent` | ローカルストレージ | 許可または拒否を選んだとき | 選択内容の記憶 | 12 か月 |
| `snaptray.attribution` | セッションストレージ | 解析を許可した後 | 閲覧中、アクセス元のキャンペーンを保持 | タブを閉じるまで、またはページ表示がないまま 30 分経過するまで |

Google アナリティクスの解析データは 2 か月間保存した後に削除されます。集計済みのレポート（キャンペーン別のダウンロードクリック数など）はより長く保存する場合があります。

選択を変更するには、各ページ下部の**解析の設定**を使用してください。許可した後に拒否すると解析は停止し、そのブラウザにある本ウェブサイトの Google アナリティクス Cookie が削除されます。

解析の数値は概算です。広告ブロッカー、許可されなかった訪問、ネットワークの問題により、一部の訪問は計測されません。

## まとめ

| 質問 | 回答 |
|------|------|
| SnapTray はデータを収集しますか？ | いいえ |
| SnapTray はサーバーにデータを送信しますか？ | アップデート確認が有効な場合のみ（バージョン文字列のみ） |
| SnapTray は利用状況を追跡しますか？ | いいえ |
| SnapTray は分析ツールを含みますか？ | いいえ |
| SnapTray は自動で外部接続しますか？ | いいえ。アップデート確認はオプトアウト可能で、バージョン番号のみ送信します |
| ファイルはどこに保存されますか？ | すべてお使いのデバイス上にローカル保存されます |
| これらの主張を検証できますか？ | はい、ソースコードは公開されています |
| snaptray.cc ウェブサイトは解析を使用しますか？ | ウェブサイトの案内で許可した場合のみ Google アナリティクス 4 を使用します。[ウェブサイト](#website)を参照 |
