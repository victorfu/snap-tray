## เริ่มจับภาพ

กด `F2` (ค่าเริ่มต้น) เพื่อเข้าสู่การจับภาพเฉพาะส่วน เคอร์เซอร์จะเปลี่ยนเป็นรูปกากบาท และตัวช่วยเคอร์เซอร์จะปรากฏตามการตั้งค่า `Cursor companion` ใน Settings

## จับภาพเต็มหน้าจอ

ใช้ `Full Screen Capture` จากเมนูถาด หรือกำหนดปุ่มลัดใน Settings > Hotkeys เพื่อจับภาพหน้าจอที่เคอร์เซอร์อยู่โดยไม่ต้องเลือกพื้นที่ ทุกจอจะได้ภาพที่ความละเอียดดั้งเดิม รวมถึงการปรับขนาดแบบไม่เป็นจำนวนเต็ม เช่น 125% หรือ 150% หน้าต่างของ SnapTray เอง เช่น หมุดและการแจ้งเตือน จะไม่ปรากฏในภาพ

เลือกการดำเนินการหลังจับภาพได้ที่ Settings > Advanced > `After full screen capture`:

- `Copy to clipboard` (ค่าเริ่มต้น)
- `Save to file` บันทึกตามการตั้งค่า Files
- `Open editor` เปิดภาพโดยเลือกทั้งหน้าจอไว้ เพื่อใส่คำอธิบายประกอบก่อนคัดลอกหรือบันทึก

ภาพที่จับจะถูกเพิ่มลงใน History

## จับภาพแบบหน่วงเวลา

ใช้ `Delayed Capture` จากเมนูถาด แล้วเลือก `3 วินาที`, `5 วินาที` หรือ `10 วินาที` เพื่อจับภาพ UI ที่หายไปทันทีที่กดปุ่ม เช่น สถานะ hover เมนูแบบเลื่อนลง เมนูคลิกขวา และ tooltip ระหว่างนับถอยหลังจะมีป้ายนับถอยหลังขนาดเล็กที่ด้านบนของหน้าจอ ป้ายนี้ไม่รับการคลิก คุณจึงเปิดเมนูหรือวางเคอร์เซอร์บนส่วนที่ต้องการได้ตามปกติ

เมื่อนับถอยหลังจบ SnapTray จะซ่อนป้าย หยุดภาพหน้าจอที่เคอร์เซอร์อยู่ แล้วเปิด Region Capture บนภาพนั้น ขั้นตอนต่อจากนี้เหมือนการจับภาพพื้นที่ปกติ และป้ายนับถอยหลังจะไม่ปรากฏในภาพ

- เมนูถาดจะจำเวลาหน่วงล่าสุดที่เลือกไว้ กำหนดปุ่มลัด `Delayed Capture` ใน Settings > Hotkeys เพื่อเริ่มนับถอยหลังด้วยเวลานั้นจากคีย์บอร์ด
- หากต้องการยกเลิก เลือก `Cancel Delayed Capture` จากเมนูถาด หรือกดปุ่มลัด `Delayed Capture` อีกครั้ง การเริ่มจับภาพอื่นระหว่างนับถอยหลังจะถูกละเว้น

## พฤติกรรมการเลือก

### การเล็งที่แม่นยำ

- โหมดแว่นขยายให้ข้อมูลป้อนกลับระดับพิกเซล
- ความกว้างและความสูงจะแสดงใกล้กับส่วนที่เลือก
- กดค้าง `Shift` เพื่อล็อกอัตราส่วนภาพ

### การเลือกที่รับรู้หน้าต่าง

เมื่อการตรวจจับหน้าต่างพร้อมใช้งาน SnapTray สามารถตรวจจับหน้าต่างที่อยู่ใต้เคอร์เซอร์ได้ เพื่อให้คุณเลือกได้ด้วยคลิกเดียว

### ยกเลิกและลองใหม่

คลิกขวาหรือกด `Esc` เพื่อยกเลิกการเลือกปัจจุบัน

## เวิร์กโฟลว์หลายส่วน

กด `M` เพื่อสลับโหมดการจับภาพหลายส่วน คุณสามารถรวบรวมหลายส่วนแล้วส่งออกเป็นเอาต์พุตรวมหรือแยกกันก็ได้

## การดำเนินการหลังเลือก

หลังจากเลือกพื้นที่เสร็จแล้ว แถบเครื่องมือรองรับ:

- เครื่องมือมาร์กอัปและแก้ไข (Arrow/Pencil/Marker/Shape/Text/Mosaic/Step Badge/Emoji/Eraser)
- `OCR` (เฉพาะ macOS/Windows; ซ่อนใน Linux beta) และ `QR Code Scan`
- `Auto Blur` (ใบหน้า + ข้อมูลสำคัญ)
- `Pin`, `Save` และ `Copy`

## ปุ่มลัดที่มีประโยชน์

| การดำเนินการ | ปุ่มลัด |
|---|---|
| เริ่มการจับภาพเฉพาะส่วน | `F2` |
| คัดลอกรหัสสีใต้เคอร์เซอร์ (เมื่อโหมดแว่นขยายเปิดอยู่) | `C` |
| ล็อกอัตราส่วน | กดค้าง `Shift` |
| สลับหลายส่วน | `M` |
| ยกเลิก | `Esc` |
