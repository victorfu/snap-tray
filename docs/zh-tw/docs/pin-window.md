## 建立釘選視窗

可由截圖結果按 `Enter`，或從托盤選單「Pin from Image...」建立。

## 核心控制

### 懸停控制條

滑鼠停在釘選圖上，底部會出現一個小控制條：

- **縮放 150%**、**不透明度 80%** 顯示目前數值；點一下打開滑桿、常用值與 **重設為 100%**。
- 即時更新進行中會顯示 **● 即時** / **⏸ 已暫停**，點一下可暫停或繼續。
- **標註** 打開標註工具列（同 `Space`），**⋯** 打開完整選單。

滑鼠離開釘選圖後控制條會淡出；拖曳、縮放邊框、標註或滑鼠穿透時不顯示。釘選圖較窄時只保留兩個數值與 **⋯**。可在 **設定 → 釘選視窗 → 游標停留時顯示控制項** 關閉。控制條上的每項功能也都有鍵盤快捷鍵（見下表）。

### 滑鼠操作

- 拖曳移動
- 滾輪縮放
- `Ctrl` + 滾輪調透明度
- 邊緣拖曳調整大小

### 鍵盤操作

| 動作 | 按鍵 |
|---|---|
| 順時針旋轉 | `1` |
| 逆時針旋轉 | `2` |
| 水平翻轉 | `3` |
| 垂直翻轉 | `4` |
| 放大 / 縮小 | `Ctrl/Cmd` + `=` / `Ctrl/Cmd` + `-` |
| 縮放重設為 100% | `Ctrl/Cmd` + `0` |
| 不透明度增加 / 減少 | `]` / `[` |
| 不透明度重設為 100% | `Ctrl/Cmd` + `]` |
| 開始 / 停止即時更新 | `L` |
| 暫停 / 繼續即時更新 | `P` |
| 從釘選圖取色（標註時） | `I` |
| 顯示工具列 | `Space` |
| 關閉 | `Esc` |

每次調整都會出現一個標明數值的小徽章，例如「縮放 150%」「不透明度 80%」。

## 右鍵選單功能

右鍵選單（也就是控制條上的 **⋯**）依任務分組：

- 檢視：顯示工具列、顯示邊框、縮放（放大/縮小、常用值、重設為 100%、平滑）、不透明度（增加/減少、重設為 100%）、影像處理（旋轉、翻轉、裁切）
- 輸出：複製、儲存、匯出為、浮水印、資訊、開啟歷史資料夾
- 模式：滑鼠穿透、即時更新（開始/停止、暫停/繼續、更新頻率）、調整區域版面
- 多張釘選圖：移到螢幕、合併釘選圖、關閉所有釘選圖
- 關閉

### 滑鼠穿透

開啟滑鼠穿透後，點擊會穿過釘選圖到下方視窗，釘選圖右上角會顯示 **滑鼠穿透 · 關閉 ✕**。點它即可關閉，也可以用系統列選單的 **關閉所有釘選的滑鼠穿透**。滑鼠穿透支援 macOS 與 Windows。

### 排列合併圖片

**合併釘選圖**保留原尺寸與自動換行的預設行為。在合併圖或多區域截圖上選擇**調整區域版面**，即可預覽原始尺寸、橫排等高或直排等寬，並調整間距及圖片先後順序。畫布編號始終對應同一張來源圖片。

預設啟用**不放大來源像素**：依輸出 DPR，以最小來源尺寸限制共用高度或寬度，並在像素取整範圍內保留比例。對話框顯示儲存圖片的實際像素尺寸；螢幕大小與顯示縮放不會決定輸出品質。關閉此選項時，採用來源中最大的原生邏輯高度或寬度。間距以輸出邏輯單位計算。

選擇**手動**會還原這次編輯中嘗試自動排列前的自由版面，接著可在畫布上移動或縮放。**取消**會還原進入編輯器前的版面；**套用**會新增一筆影像復原操作，可開啟標註工具列執行復原或重做。合併會等待自動模糊完成，並包含來源已有的標註與遮罩。合併後新增的標註沿用既有版面行為：中心跟隨來源區域，標註本身的視覺大小保持不變。

最多支援 20 張圖片、每邊 10,000 邏輯單位與 64 百萬輸出像素；無效或過大的版面會在合成前拒絕。儲存圖片與歷史紀錄沿用既有輸出管線。

### 匯出較小的副本

右鍵選單的**匯出為...**、美化面板的**匯出...**，以及素材庫的**匯出...**會開啟同一個對話框。它只會寫出衍生檔案，釘選圖、標註與素材庫項目都維持完整解析度。

- **尺寸**：原始尺寸、依百分比縮放，或限制長邊。會維持長寬比，且不會放大。尺寸以圖片本身的像素計算，因此 2x 螢幕上寬 1280 點的截圖是 2560 px。
- **格式**：PNG（無損）或 JPEG（有損）。只有選擇 JPEG 時才會出現 **JPEG 品質**；PNG 不會顯示會造成誤解的品質設定。
- **檔案大小**是即將寫出檔案的實際大小，會以目前設定在背景編碼後顯示。得到大小後才能按**匯出...**，而存出的檔案就是被測量的那一份。

JPEG 是有損格式：較小的 JPEG 並不等同於 PNG，也無法保留透明區域（會以白色填滿）。對話框匯出的是開啟當下的圖片；之後若變更釘選圖，對話框會自動關閉。儲存失敗時對話框會保持開啟，可以再試一次。成功匯出後會記住這次使用的設定。標註與美化樣式會先以完整解析度合成，再進行縮放。

## 釘選視窗內標註

按 `Space`，或點控制條上的 **標註**，即可展開釘選專用標註工具列，快速加註不需回到主截圖流程。美化（Beautify）也在這個工具列上。

- 繪圖工具：Pencil、Marker、Arrow、Shape、Text、Mosaic、Step Badge、Emoji、Eraser
- 實用工具：Crop、Measure
- 動作工具：OCR（僅支援 macOS/Windows；Linux beta 會隱藏）、QR Code Scan、Save、Copy
