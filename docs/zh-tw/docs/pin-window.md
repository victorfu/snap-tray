## 建立釘選視窗

可由截圖結果按 `Enter`，或從托盤選單「Pin from Image...」建立。

## 核心控制

### 懸停控制條

滑鼠停在釘選圖上，底部會出現一個小控制條：

- **縮放 150%**、**不透明度 80%** 顯示目前數值；點一下打開滑桿、常用值與 **重設為 100%**。
- 即時更新進行中會顯示 **● 即時** / **⏸ 已暫停**，點一下可暫停或繼續。
- **標註** 打開標註工具列（同 `Space`），**⋯** 打開完整選單。

滑鼠離開釘選圖後控制條會淡出；拖曳、縮放邊框、標註或滑鼠穿透時不顯示。釘選圖較窄時只保留兩個數值與 **⋯**。可在 **設定 → 釘選視窗 → 游標停留時顯示控制項** 關閉。控制條上的每項功能也都有鍵盤快捷鍵（見下表）。

### 滑鼠操作

- 拖曳移動
- 滾輪縮放
- `Ctrl` + 滾輪調透明度
- 邊緣拖曳調整大小

### 鍵盤操作

| 動作 | 按鍵 |
|---|---|
| 順時針旋轉 | `1` |
| 逆時針旋轉 | `2` |
| 水平翻轉 | `3` |
| 垂直翻轉 | `4` |
| 放大 / 縮小 | `Ctrl/Cmd` + `=` / `Ctrl/Cmd` + `-` |
| 縮放重設為 100% | `Ctrl/Cmd` + `0` |
| 不透明度增加 / 減少 | `]` / `[` |
| 不透明度重設為 100% | `Ctrl/Cmd` + `]` |
| 開始 / 停止即時更新 | `L` |
| 暫停 / 繼續即時更新 | `P` |
| 從釘選圖取色（標註時） | `I` |
| 顯示工具列 | `Space` |
| 關閉 | `Esc` |

每次調整都會出現一個標明數值的小徽章，例如「縮放 150%」「不透明度 80%」。

## 右鍵選單功能

右鍵選單（也就是控制條上的 **⋯**）依任務分組：

- 檢視：顯示工具列、顯示邊框、縮放（放大/縮小、常用值、重設為 100%、平滑）、不透明度（增加/減少、重設為 100%）、影像處理（旋轉、翻轉、裁切）
- 輸出：複製、儲存、浮水印、資訊、開啟歷史資料夾
- 模式：滑鼠穿透、即時更新（開始/停止、暫停/繼續、更新頻率）、調整區域版面
- 多張釘選圖：移到螢幕、合併釘選圖、關閉所有釘選圖
- 關閉

### 滑鼠穿透

開啟滑鼠穿透後，點擊會穿過釘選圖到下方視窗，釘選圖右上角會顯示 **滑鼠穿透 · 關閉 ✕**。點它即可關閉，也可以用系統列選單的 **關閉所有釘選的滑鼠穿透**。滑鼠穿透支援 macOS 與 Windows。

## 釘選視窗內標註

按 `Space`，或點控制條上的 **標註**，即可展開釘選專用標註工具列，快速加註不需回到主截圖流程。美化（Beautify）也在這個工具列上。

- 繪圖工具：Pencil、Marker、Arrow、Shape、Text、Mosaic、Step Badge、Emoji、Eraser
- 實用工具：Crop、Measure
- 動作工具：OCR（僅支援 macOS/Windows；Linux beta 會隱藏）、QR Code Scan、Save、Copy
