## 工具分類

### 繪圖

- Pencil
- Marker
- Arrow（直線與折線模式）
- Shape（矩形／橢圓）

### 說明標記

- Text
- Step Badge
- Emoji Sticker

### 隱私與修正

- Mosaic
- Eraser

## 鉛筆與螢光筆直線

使用 Pencil 或 Marker 時，先按住 `Shift`，再按住滑鼠左鍵拖曳，即可從起點到游標畫出任意角度的直線。直線沿用工具原本的樣式，包含螢光筆的透明效果；每筆直線可單獨 Undo／Redo。

起筆時的 Shift 狀態會決定整筆模式，拖曳途中按下或放開 Shift 不會切換。起筆時未按 Shift，則維持自由手繪。區域截圖、釘選視窗與螢幕畫布的操作相同。

## 螢光筆貼齊文字

在支援 OCR 的 macOS／Windows 單一擷取選區中，選擇螢光筆並開啟子工具列的「貼齊文字」：圖案是一行文字、下方另一行被框住的圖示按鈕。游標停在按鈕上會顯示說明，開啟時按鈕會填滿強調色。此偏好預設關閉。文字辨識會在背景分析原始截圖；游標移到已辨識的水平文字行時，可預覽目標行與筆寬。向左或向右拖曳都會保留你的水平端點，只調整筆畫中線與粗細。圓形端帽在視覺上可能超出端點。

拖曳鎖定一行後，移到鄰行不會切換目標。文字行有歧義、OCR 不可用，或開始筆畫時辨識尚未完成，會維持一般螢光筆行為，包括 Shift。晚到的辨識結果僅供下一筆使用；每筆仍可一次復原／重做，歷史回放不需要重新辨識。

此模式不支援段落、直排、旋轉文字，也不會延伸到完整字詞邊界。多區域擷取、釘選視窗、螢幕畫布與 Linux 不提供此模式。關閉開關即可使用一般自由螢光筆。

## 修改已畫好的標註

選取文字、箭頭、線條或形狀標註後，樣式列會顯示 **已選取：箭頭**（或你選取的類型），這時調整顏色、粗細與樣式都會套用到這個標註。按 `Ctrl/Cmd + Z` 可以復原。拖曳粗細滑桿或連續點選顏色只算一次修改。已選取的形狀不能更換類型；要畫不同的形狀，請改用形狀工具重新畫。

沒有選取任何標註時，樣式列顯示 **新物件**，調整的是下一個要畫的標註；修改已選取的標註不會改到這些設定。

移動、旋轉、縮放標註，拖曳箭頭端點或曲線，拖曳折線的點，以及重新編輯文字，各自都可以用一次復原還原。拖曳到一半按 `Esc`，標註會回到原位。

## 從畫面取色

點顏色列尾端的滴管，或按 `I`，就能從正在標註的影像上取色，例如對齊品牌色或介面按鈕的顏色。放大鏡會顯示游標下的像素與色碼。

- 點一下即採用這個顏色；也可以按住滑鼠、移動微調位置後再放開。
- 方向鍵每次移動 1 個實體像素，在 2 倍縮放的螢幕上也一樣。按 `Enter` 採用。
- 按 `Esc`、按右鍵，或在影像外點一下，會取消並保留目前的顏色。

取到的是影像本身的顏色，不會取到你畫的標註或 SnapTray 的工具列：

| 位置 | 取樣來源 |
|---|---|
| 區域截圖 | 凍結的截圖 |
| 釘選視窗 | 釘選的影像本身（套用目前的縮放、旋轉與翻轉） |
| 螢幕畫布 | 開始取色時，隱藏畫布後拍下游標所在螢幕的快照；只用於取色，結束即丟棄。白板或黑板會取到它本身的顏色。 |

有選取標註時，顏色會套用到該標註，按 `Ctrl/Cmd + Z` 可以復原。沒有選取時，顏色會成為目前顏色，並和其他選色方式一樣記到下次。螢幕閱讀器會唸出結果，例如「顏色已設為 #1A73E8」。

只要顏色列有顯示，就可以按 `I`；在文字框中輸入時除外。選取區域之前，按 `C` 仍可複製放大鏡下的色碼。

## 工具列放不下時

螢幕較窄時，較少用的按鈕會收進 **更多**（⋯），從 QR Code 與 OCR 開始。複製、儲存、釘選、復原、重做，以及正在使用的工具一定會留在工具列上。在 **更多** 選單中可用方向鍵與 `Enter` 選取，按 `Esc` 關閉。

## 建議編修流程

1. 先完成主體標線。
2. 統一顏色與線寬。
3. 補上文字與步驟編號。
4. 對敏感區域套用馬賽克。
5. 透過 Undo/Redo 微調後輸出。

## 使用建議

- 關鍵訊息維持單一強調色。
- Marker 適合高亮，不適合大量文字。
- 操作教學建議優先使用步驟標記。

## 美化（Beautify）

釘選工具列上的 **美化** 會把截圖放到背景上，方便直接分享。

- **樣式** 一次設定內距、圓角與陰影：**緊湊**、**標準**（預設）、**寬鬆** 或 **扁平**（無陰影、直角）。目前的樣式會有外框；你自己調整後會顯示 **自訂**。
- **背景** 提供八種具名漸層。換樣式不會改背景，換背景也不會改樣式。
- **自訂調整** 展開細項：背景類型（純色、線性或放射漸層）、顏色、內距、圓角、陰影、陰影模糊、邊框與長寬比。
- **儲存樣式…** 會用你取的名字保存目前整套外觀（背景、內距、圓角、陰影、邊框與長寬比）。在截圖上，保存的樣式不論截圖大小都維持相同的像素尺寸，和內建樣式一樣。保存的樣式和錄影編輯器的 **畫布** 共用：在任一邊保存的樣式，兩邊都能用；套在錄影上時，尺寸會隨影片大小縮放（影片短邊 1440 px 時與截圖相同）。這次改版前保存的樣式，外觀完全不變。保存的樣式顯示在內建樣式下方；點一下即可套用，用 **✎**（或鍵盤焦點在上面時按 `F2`）改名，或用 **×**（或 `Delete`）刪除。兩個保存的樣式不能同名。用已有的名字保存會更新那個樣式。最多保留 8 個。
- 按 **複製** 或 **儲存** 會記住這次的外觀，下次沿用。

錄影編輯器的 **畫布** 使用同一組漸層、相同名稱（背景、內距、圓角、陰影、邊框、長寬比）與同一份保存的樣式。

## 匯出動作

- `Enter` 釘選
- `Ctrl/Cmd + C` 複製
- `Ctrl/Cmd + S` 儲存
