## หน้าการตั้งค่า

หน้าต่าง ๆ จัดกลุ่มตามงาน แต่ละหน้าเริ่มด้วยชื่อหน้าและประโยคสั้น ๆ ที่บอกว่าหน้านั้นครอบคลุมอะไร Updates และ About อยู่ใต้เส้นแบ่ง

Recording และ Text Recognition ใช้ได้เฉพาะบน macOS และ Windows Linux beta ซ่อนทั้งสองหน้าเนื่องจากฟีเจอร์เหล่านั้นไม่รวมอยู่

### General

เปิดตอนสตาร์ทอัป ภาษาการแสดงผล ธีมแอป และการติดตั้ง/ถอนการติดตั้ง CLI

บน macOS หน้านี้ยังแสดงสถานะสิทธิ์ Screen Recording และ Accessibility พร้อมลิงก์ตั้งค่าระบบแบบคลิกเดียว

### Capture

- **After Capture**: สิ่งที่ `After full screen capture` ทำ (คัดลอก บันทึก หรือเปิดตัวแก้ไข)
- **Region Selector**: ตัวช่วยเคอร์เซอร์ (แว่นขยาย) และคำแนะนำปุ่มลัด
- **Auto Blur**: ประเภทและความเข้มของการเบลอที่ใช้เมื่อ Auto Blur ซ่อนใบหน้าและข้อความ

### Pin Windows

ความทึบเริ่มต้น **Show controls on hover** และระดับที่ความทึบหรือการซูมเปลี่ยนในแต่ละขั้น

### Recording

เฟรมเรต รูปแบบเอาต์พุตเริ่มต้น พฤติกรรมการส่งออกแบบดูตัวอย่างก่อน แหล่งเสียง/อุปกรณ์ และการนับถอยหลัง

### Saving

- โฟลเดอร์สกรีนช็อตและการบันทึก รวมถึงเทมเพลตรูปแบบชื่อไฟล์
- การบันทึกอัตโนมัติและ **Remember last folder**: เมื่อเปิด กล่องโต้ตอบ Save As ของ Region, Pin, Beautify และ Library จะเปิดในโฟลเดอร์ที่บันทึกภาพด้วยตนเองสำเร็จล่าสุด ส่วนการบันทึกภาพหน้าจออัตโนมัติยังคงใช้โฟลเดอร์ภาพหน้าจอ
- **Watermark**: ภาพลายน้ำ ว่าจะใช้กับสกรีนช็อต/การบันทึกหรือไม่ ความโปร่งใส ขนาด ระยะขอบ และตำแหน่ง พร้อมตัวอย่าง
- **Library**: จำนวนสกรีนช็อตที่ Library เก็บไว้ เมื่อเกินจำนวนนี้ ภาพที่เก่าที่สุดจะถูกนำออกจาก Library ส่วนไฟล์ที่คุณบันทึกไว้ยังอยู่ที่เดิม

### Text Recognition

ลำดับภาษา OCR และพฤติกรรมหลังการรู้จำ

### Hotkeys

ตัวแก้ไขปุ่มลัดแบบรวมศูนย์ตามหมวดหมู่การทำงาน รีเซ็ตปุ่มลัดแต่ละรายการได้ และ **Restore All Defaults** จะรีเซ็ตทั้งหมด

### Updates

เวอร์ชันปัจจุบัน ช่วงเวลาตรวจสอบอัตโนมัติ สถานะตรวจสอบล่าสุด และการตรวจสอบด้วยตนเองทันที

### About

ชื่อแอป เวอร์ชัน ลิขสิทธิ์ ผู้เขียน และลิงก์เว็บไซต์

## ค้นหาและรีเซ็ตการตั้งค่า

- **Search settings** ที่ด้านบนของแถบด้านข้าง (`Ctrl+F` หรือ `Cmd+F` บน macOS) ค้นหาการตั้งค่าได้จากชื่อ ส่วน (เช่น "watermark") หรือหน้า และค้นหาปุ่มลัดได้จากชื่อการดำเนินการ ใช้ `Up`/`Down` และ `Enter` เพื่อเปิดผลลัพธ์ SnapTray จะสลับไปยังหน้านั้น เลื่อนไปที่การตั้งค่า และไฮไลต์ไว้ครู่หนึ่ง กด `Esc` เพื่อล้างการค้นหา
- การตั้งค่าจะบันทึกทันทีที่เปลี่ยน เมื่อการตั้งค่าใดต่างจากค่าเริ่มต้น ปุ่ม **reset** จะปรากฏทางซ้ายของชื่อ และคืนค่าเฉพาะการตั้งค่านั้น ปุ่มลัดยังคงมี **Reset** และ **Restore All Defaults** ของตัวเอง การตั้งค่าที่ขึ้นกับระบบหรือเป็นตัวเลือกที่มีแต่คุณเท่านั้นที่ตัดสินได้ เช่น ภาษา ธีม การเปิดเมื่อเข้าสู่ระบบ อุปกรณ์อินพุต ภาพลายน้ำ หรือภาษา OCR จะไม่มีปุ่มรีเซ็ต

## โปรไฟล์พื้นฐานที่แนะนำ

- บน macOS/Windows ใช้ MP4 ที่ 30 FPS สำหรับบทช่วยสอนมาตรฐาน
- โฟลเดอร์เฉพาะสำหรับสกรีนช็อต และการบันทึกในกรณีที่ใช้ได้
- เปิดการตรวจสอบอัปเดตอัตโนมัติรายวัน
